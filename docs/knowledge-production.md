# 知识库制作模板

[组织清单](../resources/packs/knowledge-production/pack.yaml) 定义知识库负责人、编辑和审核员，以及作品工作方式、产物约定和 Ollama 向量化插件引用。员工技能以各自定义为准。三名员工使用 `okf` 和 `knowledge-search`，负责人另用 `project-coordination` 协调制作。具体分工和返修流程见 [组织工作方法](../resources/packs/knowledge-production/playbook.md)。

从 Workbench 广场安装模板并创建制作组织。创建前按计划核对准确依赖。正文发布、检索和跨组织授权遵循应用的 [知识库使用说明](https://github.com/huangjiaroro/zero-point-workbench/blob/v1.0.0/docs/knowledge-library.md)。
