# 文档检查与渲染

先取得当前任务获准文档的实际路径和版本；作品文件或参考资料通过 Workbench 阅读工具定位。读取 [工具入口](../../WORKBENCH-TOOLS.md)，通过 `list_plugins` 取得本轮准备好的 `wb-document`，输入 JSON 和检查输出保存在本轮 work/outputs。

需要来源核验和结构统计时使用 `document.inspect`；需要真实显示检查时使用 `document.render`，其 paths 只放本次要检查的文件。新增或修改 Mermaid、渲染方式变化时检查实际图和错误；仅修改正文或引用时检查相应段落与入口，未变图有适用的准确验证证据时复用。既有包不因一段文字修改就默认全包重新渲染。

插件统一准备固定运行依赖与浏览器。渲染时调用准备好的命令，不逐任务安装工具、搜索宿主浏览器或借用其他员工的依赖目录。缺少可用环境时报告准确失败和未检查项，按宿主准备与恢复入口处理。

核对返回的来源路径、SHA-256、渲染状态、错误与实际 HTML。失败文档不能报告通过；保存成功的页面可供进一步查看，但不能只凭存在页面就断言排版合适。检查完成后回传本次文件和图的范围、实际结果与未验证项，保留已有准确版本和来源标签。

统计、渲染与专业审查分别报告。工具不判断故事质量、业务规则或方法改善，也不授予读取和写入权限；二进制、PDF 或非 UTF-8 文档明确报告不支持。
