# 作品资料

在插件广场安装到工作台，再在组织中启用此插件后，工作协同页面会自动提供入口，不需要为员工安装界面 Skill。

员工可调用 list_workbench_views，再以 pluginId=project-materials 与贡献标识调用 open_workbench_view；展示状态以 get_workbench_view_request 为准。

界面合并宿主提供的文档和媒体摘要，按正式产物目录生成可折叠业务树；读取 asset-registry.json 显示素材名称及引用，读取每集 production.json 的 clips 顺序与 Shot 对应。点击分类查看总览，点击对象在右侧查看当前正文、媒体、实际 Prompt、参考及关键帧。关键帧在对应 Clip 详情按索引源时间展示，点击图片在详情区预览；不把抽帧视作已验收。archive/ 不进入主目录或正式数量，在所属对象详情按原样浏览，无需版本索引。缺失文件或索引读取异常明确提示，不猜测采用状态。员工按产物契约保存结果，页面随文件变化更新。

本插件提供工作页面，不需要配套操作技能或安装准备脚本。专业阅读与创作方法由员工的独立技能或其他已启用插件提供，不由页面代替。
