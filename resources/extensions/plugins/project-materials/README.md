# 作品资料

在插件广场安装到工作台，再在组织中启用此插件后，工作协同页面会自动提供入口，不需要为员工安装界面 Skill。

员工可调用 list_workbench_views，再以 pluginId=project-materials 与贡献标识调用 open_workbench_view；展示状态以 get_workbench_view_request 为准。

界面按实际文件展示作品文档和媒体，支持文档打开与媒体预览。整体故事设计列在故事设定，单集戏剧设计列在对应集的编剧阶段。导演规划依次展示整体方案、表演设计、镜头规划和背景音乐规划。同目录的其他文档以原文件名显示。目录分组用于浏览，交付状态以实际验收为准。员工按组织产物契约保存结果，页面随文件变化更新。

本插件提供工作页面，不需要配套操作技能或安装准备脚本。专业阅读与创作方法由员工的独立技能或其他已启用插件提供，不由页面代替。
