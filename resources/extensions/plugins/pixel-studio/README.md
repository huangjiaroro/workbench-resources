# 像素工作室

在插件广场安装到工作台，再在组织中启用此插件后，工作协同页面会自动提供入口，不需要为员工安装界面 Skill。

员工可调用 list_workbench_views，再以 pluginId=pixel-studio 与贡献标识调用 open_workbench_view；展示状态以 get_workbench_view_request 为准。

界面只读取声明的数据摘要，不执行媒体生成，不改变产物审批状态。

工作室直接在人物与气泡上展示团队状态，不另列重复的员工卡片。悬停可查看完整任务摘要，点击人物或气泡打开员工档案；键盘可用 Tab 选中人物，再按 Enter 打开档案。

本插件以工作页面提供可视化工作室；专业制作与审查方法由相应技能维护。页面不重复分发这些独立方法，也不要求安装空的配套技能或准备脚本。
