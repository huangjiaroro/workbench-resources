# 媒体检查

需要了解实际视频、图片或音频文件，提取指定画面或声音证据时使用。命令见 [插件入口](../../WORKBENCH-TOOLS.md)，字段与支持边界见 [参数说明](../../README.md)。

1. 取得准确文件路径与 SHA-256；直接使用作品成果或本轮 inputs/work/outputs 路径。缺少路径时回查对应记录，不扫描电脑寻找同名文件。
2. 先查看准确来源对应的已有输出；所需时间点缺失、清晰度不足或来源版本变化时再补抽。在本轮 work 写 JSON：`path` 为准确文件；按目的选择 `frameTimes`（秒）和 `extractAudio`。不确定时长时先只检查信息，再选实际时长内的时间点。静态图片或纯音频不传抽帧时间。
3. 运行 `wb-media inspect --input <参数文件绝对路径> --output-dir <本轮 outputs 绝对路径>`。macOS 和 Windows 参数相同；含空格路径作为一个完整参数。读取退出码、state 和真实 resultFile，失败保留原错误，不换程序或重写工具。
4. 结果记录来源哈希、请求和实际源帧时间、派生文件路径。作品任务的 outputs 属于本作品共享工作区，有权限的员工通过准确文件与 result.json 引用直接读取，无需复制或重复处理；旧版本输出保留。
5. 用本次实际可用的看图、播放或听音工具检查派生内容，明确检查了哪些帧、哪些时间范围。容器参数、音轨存在和抽帧成功不能证明全片运动、台词、口型、节奏或声音质量合格。无法查看或收听时明确待审项。

工具缺失或损坏交由插件维护页修复，不全盘搜索 FFmpeg、不修改系统环境。专业连续性、创作或音乐判断继续使用相应独立技能。
