# 视频拼接

需要把已确定的实际视频按顺序导出时使用。先读 [插件入口](../../WORKBENCH-TOOLS.md) 和 [支持边界](../../README.md)；检查源素材时读 [媒体检查](../media-inspection/SKILL.md)。

1. 从准确采用清单读取每段的顺序、mediaId、哈希、版本和实际获准路径。不能从文件夹选“最新”视频，也不重复片段凑数量。仅一段时按实际需求直接复用原文件。
2. 在本轮 work 写参数 JSON：`paths` 为 2 至 100 个有序绝对路径；`audioPolicy` 明确 preserve 或 mute。默认保留原声，静音必须符合已确定的方案。混合分辨率、帧率、方向或声音布局时先明确规范化方案；本命令会拒绝，不能靠静音或裁切绕过。
3. 运行 `wb-media assemble --input <参数文件绝对路径> --output-dir <本轮 outputs 绝对路径>`。macOS 和 Windows 相同，路径按当前 Shell 正确引用。检查真实退出码、state 和 resultFile。
4. 读取各段来源哈希、起点和时长，核对实际导出视频参数与声音策略，保存导出视频到成果或输出目录。登记真实有序来源和输出哈希。
5. 重新查看导出片的顺序、接缝、重复动作、声音和时长，记录实际范围与未检查项。不能用源片通过或导出成功推导成片验收通过。

本插件首版只做简单拼接，不支持字幕烧录、配音混入或复杂转场。缺少工具或环境损坏时报告并修复当前插件，不能搜索整盘、安装系统工具或临时改写导出脚本。

长时间编码使用本插件的 `wb-media assemble`；它不设固定 FFmpeg 执行期限，外层 Windows 命令工具的 `timeoutSeconds` 也保持 0。不要从插件工具环境提取 FFmpeg 路径后在 PowerShell 中自行拼接滤镜标签。
