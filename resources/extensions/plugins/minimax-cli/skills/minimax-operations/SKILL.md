# MiniMax 调用方法

使用本插件的视频、图片、语音、识图、搜索或文本能力时使用。先读 [插件命令说明](../../WORKBENCH-TOOLS.md)，再按需要读 [示例](../../README.md)。镜头设计、视频连续性和声音审查使用相关专业技能。

1. 使用本轮插件元数据给出的 configurations 路径，明确选择账号，命令追加 `--connection <配置路径>`。不得读取个人 `~/.mmx`，不得输出配置正文。
2. 先运行相应 `mmx … --help` 核对官方参数。素材使用获准的实际文件路径，提示词和请求文件放本轮 work，下载放本轮 outputs；包含空格的路径作为一个参数传递。
3. 默认等待完成并下载。仅确有后台执行需要时使用 `--async`，保存返回的原任务 ID。超时、中断或提交状态未知时先用原连接查询已有任务；不盲目重提、不换账号。按对应命令帮助执行 task get 与 download。
4. 核对真实文件、来源任务及哈希后保存到成果或输出目录。生成成功不代表已看图、看视频或听音；检查范围和未验项如实记录。

本插件已固定官方 CLI 版本。不要运行 auth/config/agent/update，不另写 SDK 或安装系统命令。命令缺失时保留错误并修复当前版本的插件工具环境。
