# 导演场面与镜头的计划连续性（整体方案/表演/镜头）

这里记录导演规划中的空间与状态；计划决定应与实际制作记录分别识别。

## 需要检查的 15 个连续性维度

| 维度 | 导演核对要点 |
|---|---|
| 面部与身份 | 同一人，痣、疤、脸型的侧别不变 |
| 发型 | 长度、分缝、束发和湿度是否因事件改变 |
| 服装 | 各层、领口、衣袖、开合状态能否承接 |
| 道具 | 同一物件、具体拿在哪只手、方向与液位 |
| 湿、污、血 | 污损区域和程度，不能无故恢复 |
| 伤势与妆容 | 位置、时间发展和可见性有依据 |
| 光源方向 | 同一场景光源在世界空间方向一致 |
| 日夜时间 | 太阳高度、灯光开关和阴影长度一致 |
| 天气 | 风雨方向、强度及地面湿度合理 |
| 场景地理 | 门窗家具与空间图一致，不因切镜换墙 |
| 屏幕方向 | 人物朝向和移动方向符合关系轴，越轴有意图 |
| 视线关系 | 目光目标、角度、高度与其他人物位置一致 |
| 摄影机高度 | 机位高度变化有导演决定，反打空间合理 |
| 色彩 | 同一时刻色调、主色和强调色没有无依据跳变 |
| 焦段视觉感 | 相邻机位的透视变化是导演选择而非意外漂移 |

## 关键状态轨迹

导演按场次建立稳定事实：角色身份与衣着、真实空间站位/朝向、当前持物和手别、伤痕与衣物状态、光源/天气/时间。表演阶段记录关键变化，Shot 继承并按需记录 `进入状态 → 发生变化的动作 → 离开状态`，未发生变化的状态可引用上一节点。

**例：** S12 角色右手拿证书 → S13 右手将证书递出、对方左手接过 → S14 证书在对方左手；如果 S14 出现证书还在原角色右手却无取回动作，属于计划冲突。

世界空间与画面左右分开；关系轴变化要由真实走位或可理解的画面转场解释。导演规划的计划状态不等于生成后真实状态。图像、实际媒体、种子、Prompt 和重试账本属于视频制作人。
