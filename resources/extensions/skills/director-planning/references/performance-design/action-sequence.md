# 完整表演过程与状态

按原场次从入口状态连续排演至出口状态。先确认发生的事情及相互关系，再具体化必要动作，保证每项有因果、有承接。

1. 建立当前人物位置、朝向、可接触物件、手中物、环境和注意对象；继承导演方案的空间图与前场结果。
2. 对有过程的动作写清起因/准备、实施、结果及相关反应；不强制每项都写四段。当动作本身已清楚，直接承接。将环境、道具、声音随事件发生的变化一并表达。
3. 写明谁先发生、谁因何回应、哪些动作或对白同时进行、哪些需等待前一事件完成。多人场面避免所有人先后独立演完；要能想象人物同处于一个空间。
4. 记录关键状态的改变：人物位置、持物及手别、姿态、伤损、光色、环境等；后续必须继承。参见 [计划连续性](../continuity/continuity.md)。
5. 逐场核对原文动作、发言及事件，辨别剧情必需和可以自主设计的表演细节。若场面矛盾无法通过表演解决，找主创协调编剧。

## 多人反应的并行编排

从共同事件出发，逐人确定反应条件。有人直接看到变化，有人只听到声音，有人通过另一人的动作才察觉。先排直接反应，再排因他人反应触发的后续，最后把继续发生的对白、环境声和角色原有动作放回同一过程。可以同时响应同一刺激，也可以故意齐动形成喜剧效果。若各自有不同的判断和意图，就给他们不同的起势或反应次序。

## 复排时定位缺口

从入口顺读一遍，在关键节点问三件事：人物此时知道什么，身体或物件能否从现有位置完成这个动作，观众能否从行为理解关系变化。人物若提前演出稍后才知道的结果，回到该人物的刺激与反应重排。多人互相等待、关键动作缺前因或道具突然换手时，回到对应节点补齐触发、并行关系或状态承接，再同步离开状态。

例如动作片中，对方受惊→主角启动→对方作出防御反应→物件发生位置变化→双方形成新状态；有意义的动作可拆出多个发生节点，但不等于要切多个镜头。不标秒数、镜头编号、机位或硬切候选。
