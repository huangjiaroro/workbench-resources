# 表演设计执行索引

输入：锁定 Script、episode-design、有效 director-plan 及必要连续性依据。按原剧本场次建立完整表演。

| 步骤 | 输入与依赖 | 方法 | 内部设计结果 |
| --- | --- | --- | --- |
| P1 视听具象化 | Script、A1 表达重点 | [视听具象化](visualization.md) | 逐场需实际发生的事件、可见可听变化及关键结果 |
| P2 人物表演 | P1、编剧人物意图 | [人物表演](acting-direction.md)；按需专项 | 具体身体动作、表情、视线、发声、听者与互动反应 |
| P3 场面调度 | P1、P2、A3/A4 空间与状态 | [场面调度](../staging/blocking-and-staging.md)；按需专项 | 人物移动路径、位置和方向变化、物件接触与多人空间关系 |
| P4 完整表演编排 | P1–P3、前场离开状态 | [动作序列](action-sequence.md) 第 1–4 步 | 按实际发生顺序整合动作、对白、反应、环境变化；明确因果、并行关系、关键状态与结束状态 |
| P5 表演完整性检查 | P4、锁定 Script、A3/A4 基准 | [动作序列](action-sequence.md) 第 5 步、[计划连续性](../continuity/continuity.md) | 覆盖完整且空间、物件、人物状态自洽的连续表演，可直接供镜头设计选择观看位置 |

P2 与 P3 随互动和空间条件反复协调；两者成立后由 P4 整合完整过程。P5 若发现动作无法执行、因果缺失或原文未覆盖，返回相关步骤修订并重新核对；空间基准需变更时同步总体方案。

当剧本只有情绪描述、多人对同一刺激作出不同反应，或对白、动作与环境变化需要同时编排时，参照[祠堂狂笑表演案例](examples/ancestral-hall-performance.md)。案例从原文区分必须保留的事件与可设计的表演细节，展示 P1–P5 如何形成可连续排演的表演节点。

专项仅在有实际问题时读取：

- [动画表演](specialties/animation-performance.md)：夸张、姿态、预备/跟随、节奏反差。
- [动作场面](specialties/action-choreography.md)：追逐、动作交锋、接触反馈与空间清晰。
- [特效动作](specialties/vfx-choreography.md)：施法、能量、幻象、环境反馈。

依题材选读专项，将其用于当前表演问题；场面调度的摄影示例用于理解空间表现，实际摄影选择由镜头阶段完成。

按 [表演设计模板](../../assets/performance-plan-template.md) 交付 `performance-plan.md`，以可追溯的完整表演过程供镜头设计承接。
