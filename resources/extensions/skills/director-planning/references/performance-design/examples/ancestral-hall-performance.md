# 祠堂狂笑｜从剧本到完整表演

本案例改编自《坏妖怪培训班》EP008 的祠堂片段。原文来自剧本节选，以下空间和表演细节是教学设计。适合参考多人同时在场、反应有先后、剧情声音与环境变化相互关联的场面。正式表演设计按[表演设计模板](../../../assets/performance-plan-template.md)记录。

## 剧本依据

| 原文位置 | 剧本节选 |
| --- | --- |
| 原文 ① | 面对全家密不透风的道德围剿，堂心的李厚依旧沉静如生铁，唯有宽阔的双肩突然微微耸动。 |
| 原文 ② | 噗……呵……哈哈……哈哈哈哈哈哈！ |
| 原文 ③ | 李厚猛然仰天暴发出排山倒海般的地动山摇狂笑！震得供案上数百块祖宗牌位东倒西歪，青铜香炉嗡嗡震响！ |
| 原文 ④ | 李父：“大逆不道！你当着祖宗牌位笑什么？！” |

本段的导演表达是围攻者因狂笑而失去主动，李父试图用斥责重新控制局面。空间基准设为供案在北，李厚立于堂心朝南，李父在他南面朝北，李母与李宝在李父西侧。李宝初始站在李母东侧，可沿她身侧向西缩到她背后。李父入场以右手拄杖，李厚面朝围攻者，供案上的牌位与香炉起初静止。

## P1–P3 形成可排演的选择

| 步骤 | 判断与做法 |
| --- | --- |
| P1 视听具象化 | 将「沉静如生铁」落实为李厚身体沉住、维持原站位。肩颤是最早可见的异常。将短笑逐渐失控及仰头狂笑兑现为声音和身体变化，保留牌位歪斜、香炉振响两个真实事件。 |
| P2 人物表演 | 李厚先压住笑声，最后放开。李宝先看李厚，听到香炉异响后才转向供案，随后缩到李母身后。李父本来直视李厚，失衡时先稳住拐杖，再抬眼斥责。听者各自因所见或所闻作出反应。李父的原话完整保留，以重新稳住的身体和刻意抬高的声量表现他试图恢复威严。 |
| P3 场面调度 | 李厚的站位提供稳定参照。李宝沿李母身侧向西后撤，停在她背后；李母留在原处。李父只朝南退半步，右手重新握稳同一根拐杖，身体仍朝北。两人的退让方向和停留位置都在既定空间内成立。 |

## P4 整合表演节点

**进入状态**　全家仍面朝李厚施压。李厚低头站定，父亲右手拄杖，李宝还在李母身侧，供案静止。

| 表演节点 | 原文位置 | 完整可表演过程 | 产生的关键状态 |
| --- | --- | --- | --- |
| P001 | ① | 指责仍在持续。李厚低头站定，双肩从静止转为轻颤。 | 双脚位置不变，肩颤成为笑声的前兆。 |
| P002 | ②前半 | 李厚嘴角扬起，以短促的「噗……呵……哈哈……」发声，逐渐抬起头。 | 周围的视线转向李厚。笑声由压住转为外露。 |
| P003 | ②后半、③ | 李厚猛然仰头，放出「哈哈哈哈哈哈！」。狂笑持续，数百块牌位受震后陆续歪斜，青铜香炉同时发出嗡鸣。 | 供案状态改变，原先的围攻停住。 |
| P004 | ③的表演反应 | 在 P003 的笑声中，李宝听到香炉异响，视线从李厚转向供案，再沿李母身侧后缩并躲到她背后。李父听到异响后向南失衡半步，右手仍触着拐杖，握力松了一下。 | 李宝留在李母背后，李父站在退后的新位置。两人的撤退在笑声中发生，触发点和方向各有区别。 |
| P005 | ④前的表演承接 | 李父在退后的新位置重新握稳拐杖，抬眼朝李厚。狂笑收尾，他随即开口。 | 拐杖始终在右手，父亲站稳，视线回到李厚。 |
| P006 | ④ | 李父喊出「大逆不道！你当着祖宗牌位笑什么？！」，两句之间有一次短气口。李厚在指责声中把视线落向李父，脸上余笑仍在，保持沉默。 | 李父尝试用斥责恢复主动。李厚仍站在堂心，牌位保持歪斜。 |

**离开状态**　李厚站位未变，朝南看李父。李宝仍在李母背后。李父较原位退了半步，拐杖握在右手，仍朝向李厚。牌位歪斜，香炉嗡鸣已转为余振。

## P5 排演复查

- **原文保真**　①的肩颤、②的完整发声、③的仰头狂笑与真实环境后果、④的完整对白和说话者均可定位。
- **刺激和反应**　先有狂笑及环境异响，李宝才转视线后缩，李父才失衡。若一开场两人已经退开，就把反应移回 P004，恢复正确的触发顺序。
- **并行**　P003 和 P004 有重叠。笑声、牌位变化、香炉声与众人反应共同组成同一段戏。李父在 P005 稳住后，再按 P006 说出原话。
- **状态**　按入口到出口核对李宝的移动路径、李父的站位和右手拐杖、歪斜的牌位。后续承接这些结果。
