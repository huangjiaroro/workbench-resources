# 专项：施法与特效动作

特效是世界中发生的变化而非画面装饰。按动作序列方法明确起因/预备（力量在哪里）、触发与释放（由谁而起）、传播路径与目标、接触反馈、余波和消散或保留。简单特效不必填全链。

- 明确能量来源、颜色/形态、运动方向、尺度变化、与人物/物件的空间关系；保留已锁定的视觉身份。
- 人物表演与特效因果一致：身体和道具姿态、阻挡或闪避、相互反作用；对撞可产生有方向的环境影响。后续继承破坏与残余状态。
- 神话幻象可以有非现实尺度和运动，但仍遵守本剧设定。特效不遮掉关键剧情动作或让人物忽然消失。
- 示例：青龙刀气沿刀锋释放；对手作出抵挡动作；两股力量接触，产生颜色明确的放射冲击与环境震动；碎石和尘雾沿冲击扩散。先完成事件过程，后续选择观看节点及时间。
