# 专项：动画表演

适用于 3D 漫剧、卡通夸张及非真人动作。不代替通用人物表演方法。

- 清晰姿态和重心：重要情绪与行为呈现在可辨认的身体轮廓、方向和姿态变化中；不依赖连续抽象情绪词。
- 预备、实施、跟随：重要动作前的意图与重心转移、实施时的力度、结束后惯性与身体余量。快速动作仍需读得懂因果。衣物、头发等可跟随主动作。
- 夸张服务角色与情境：对比幅度、紧张与释放、快慢、静与动。主体动作清楚后再安排少量次要动作；避免面部、手、全身各自主导而抢夺焦点。
- 喜剧反差：让角色特有的表情、身体响应和声音形成预期落差；对照剧情保留夸张效果，不把所有表现改成写实。

时间由后续动态时序确定，不使用固定帧数或动作时间表。
