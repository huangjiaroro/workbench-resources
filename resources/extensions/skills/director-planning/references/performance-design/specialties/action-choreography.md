# 专项：虚构动作场面

适用于武侠、战争、追逐等影视表演。以故事意图、空间可读性、角色行动和画面反馈为主，不把设计写成现实伤害操作教程。

- 先确定角色相对位置、朝向、运动方向和道具归属；每一次位移都能接回下一状态。
- 动作应有清楚的动势、准备、接触事件、受力反馈和后续结果。根据动画/写实风格表现重心变化、惯性、服饰与碎屑跟随；武器不会凭空换手、变形或穿透。
- 双方行为互相作用：攻击、防御、闪避、反应与追击应属同一因果，避免彼此独立摆造型；必要时写明同时发生的响应。群战先保证主要关系可理解。
- 场景的受影响状态（尘土、倒塌、碎裂）应有来源、扩散和继承。保持力量差异与角色战斗气质，不无故升级能力。

不设每秒动作数、固定攻击模板或镜头长度；具体观察方式由 Shot 设计决定。
