# 戏剧理解与导演节奏

以 Script 的事件、动作、对白及已有 episode-design 的人物意图为依据；无单集设计时，从正文中的行动、语言和结果推导戏剧意图，发现观众体验中真正有意义的变化。戏剧节拍（Beat）是目标、压力、关系、情绪或信息状态发生变化的戏剧单位，用于理解和安排表达，而不是摄影机切换的单位。

1. 对照场次进入与退出状态，理解人物目标、阻碍、局势和观众知情差异。
2. 沿剧本辨认关键戏剧变化及其原因：哪一行为导致关系变化，哪一信息使观众重新理解局势，何处形成期待、延宕与释放。
3. 确定导演的表达重点：观众需要先感到什么、随后发现什么；何处需要蓄势、反差、沉默、突变或余韵；哪些表演和场面关系会支撑它。
4. 在总体方案的对应场次记录关键事件、变化及节奏意图。引用编剧已定的相关意图并落实导演取舍。

例如祠堂逼债中的李厚：压迫积累 → 反常狂笑打破预期 → 宣布死士安家费，制造家人误以为他妥协的欢喜 → 公布亲弟随营，释放反转 → 众人求饶与拖行。重点在笑前的压抑、家人误判的喜悦和反转后的惊恐对照。这个节奏意图交由表演设计落实；具体哪一反应需要换镜头，由镜头阶段决定。

按场次记录戏剧重点、表达意图及快慢张弛的变化，具体播放时长在 D4 根据完整表演推导；表演与镜头覆盖采用原剧本和实际表演节点的定位。一个连续表演或镜头可以跨越多个戏剧节拍。
