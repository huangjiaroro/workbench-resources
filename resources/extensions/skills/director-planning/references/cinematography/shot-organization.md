# D3｜整场镜头组织与摄影设计

## 先组织镜头，再写逐 P 时序

以 D1 的观看路径、D2 的净发声估计、P4 的完整表演和 A 的空间基准为输入。先从整场的播放体验组织实际镜头，不按逐 P 表格的行数生成 Shot。

1. 顺读完整场次，找出戏剧转折、反应触发、动作接触及结果、重要信息的揭示等观看节点。对白连续时，声音与观看主体分别组织；尤其留意听者、接触点和旁观者。使用 [D1 表演与镜头设计对应表](performance-to-shot.md#表演或戏剧变化与镜头设计) 比较候选画面。
2. 按实际观看任务划分连续镜头：决定哪里切、哪里以同镜中的表演或摄影变化承接。可以一个 Shot 覆盖多个 P，也可以一个 P 内跨镜；新的视点有价值时积极切换，不必等待发言结束。同镜的依据是观众能持续看到有意义的变化，而非只因同一说话人、同一 P 或动作连续。切镜也不必机械遵循 P 边界。
3. 结合 [电影镜头语言](cinematic-language.md) 与 [剪辑语言](editing-language.md) 设计每个 Shot 的摄影路径、构图、声画及连接：起始机位和终态、焦距、画面主体、轴线、运动与焦点、实际切点事件、跨镜发声词句。空间必须可执行；30° 等经验用于检查连接，不作为拒绝切向其他主体的理由。
4. 完成整场并串看：依据下面的节奏参照，以 D2 和动作过程预判观看停留时间；需要更有表现力的视点时调整覆盖。不以固定镜头数、P:Shot 比例、技术 Clip 时长为依据。完整镜头组织写入临时工作稿：每个 Shot 一条，记录覆盖的 P（跨镜时明确词句或动作边界）、主体、镜头起止与运动、切点及声画连接。先完成全集的组织，再在 D4 按 P 写详细时间轴。

## 按观看任务判断停留

按正常播放顺序读过实际动作与声音，找出观众第一次看清关键信息的位置，再判断余下的停留是否仍在积累情绪、等待结果或改变人物关系。用下面的问题组织切点和观看方式，必要时回 D1 调整观看需要。

| 观看任务 | 何时可以切 | 什么时候多留 |
| --- | --- | --- |
| 突发或连续动作 | 起因与动作方向已清楚，下镜能接住接触或后果 | 受力、落点或人物选择要在当前视角里才能看清 |
| 反应与喜剧落点 | 观众已看清人物态度变化，后续只重复同一表情 | 反应由忍住到失态，或短暂停顿仍在积累预期 |
| 道具与线索揭示 | 观众已定位关键细节，并理解它对当前行动的意义 | 还需辨认文字、比较两处痕迹或观察道具状态变化 |
| 空间建立或多人调度 | 下一个动作所需的出入口、人物方位和行动方向已经清楚 | 走位正在改变围堵、追逐或交锋的关系，连续观看更容易理解 |
| 对话、悬念与情绪余韵 | 当前表演已兑现观看任务，可切向承受后果的人，必要时让声音延续 | 同框仍在呈现攻防，或沉默正在形成压力、误判与等待 |

将相邻镜头连起来看。若连续几个镜头重复证明同一信息，考虑合并视角或提前切向后果；若揭示过快，先检查观众能否辨认信息，再决定延长、改善构图或调整前后镜头。保留剧本要求的动作和完整对白。

### 连续对白的观看节奏

依据 D2 的实际发声时间，沿播放顺序检查观众持续观看同一说话者、且画面任务未实质变化的时长。跨多个 P 的同 Shot 要合计，几个仅改变景别而仍重复同一内容的 Shot 也要合看。以下是竖屏短剧规划的试排参考，用来触发观看方案比较，并非每镜的固定时长或强制切点。

| 连续观看时长 | 设计判断 |
| --- | --- |
| 不超过约 3s | 让重要表演或信息落地，避免还没看清便切走。 |
| 约 3–5s | 根据下一语义或动作变化决定继续观察、镜内转移或切镜。 |
| 约 5–8s | 比较听者、关系、证据、接触动作等实际存在的候选画面；确有持续进展时可保持当前观看。 |
| 约 8–12s | 检查每个语义节点的可见变化及被遗漏的反应，通常应组织新的观看任务；如保持同框或长镜，写清可观察的表演、关系或镜内变化及时间。 |
| 超过约 12s | 通常组织多个有意义的观看节点与相应镜头，必要时用镜内调度完成观看转换；持续观看同一主体须由具体可见变化、等待或实时行动支撑，而非只以压迫感、沉浸感或完整发言解释。 |

如新的观看主体需要另一个机位，切镜与原发言并行；不延长、缩短或打断表演以满足区间。长镜头中不断发生有意义的可见变化时，可以远长于上述区间。
