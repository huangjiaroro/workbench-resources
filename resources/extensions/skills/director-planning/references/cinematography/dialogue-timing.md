# D2｜逐 P 对白估时

以 P4 的表演段落、说话人、对白原文及发声设计为直接依据。有适用且对应当前版本的录音时采用实际发声时长，否则取得可复算的规划估计。中文首次估时或对白改变时，在技能根目录实际运行脚本（Node.js，单个字符串参数，去除说话人和舞台提示）：

```bash
node scripts/estimate-dialogue.mjs "这是黑市最新呈送的纯血贡品，"
```

按每个有对白的 P 及说话人分别计算，可以批量执行多次命令，不将不同 P 合成一个无法追溯的总估时。脚本统计汉字、数字及参考语速区间，不包含外语发声、停顿与动作；外语另用对应语言的可复算估计。结合表演选择语速，按 P 记录字数、语速或录音依据、净发声时长，保存 D2 工作结果供 D3/D4 使用；最终填入规划表的「对白估时」字段，无对白记「—」。准确有效的已有估时可复用，无实录结果属于规划估计。

连续发言跨 P 仍保持自然发声连续。D3 决定跨镜发言和观看位置，D4 根据实际词句分配跨镜发声，拆行时填该行承载的估时，合计与原 P 的净发声容量一致。多人发声注明各自容量和重叠关系。独立停顿、气口、喘息与不可重叠动作在 D4 安排；画面切换不自动增加语音停顿。不另交付独立对白估时文件。
