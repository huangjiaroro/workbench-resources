# D1｜逐 P 戏剧表达与观看设计

核心判断：此刻最值得观众看见、听见的变化是什么，由谁或什么承担？以整场 P4 表演序列及 A1 的戏剧表达组织观看路径，作为 D3 摄影与剪辑的依据。

1. 顺读整场 P4，逐 P 确定表达重点：正在发生的戏剧变化、最佳观看主体、观众此刻需要获得的信息或体验。同步考虑行动者、承受者、旁观者、物件与空间的实际变化。
2. 针对重要戏剧变化，找出实际可观察的候选主体与细节：发言者、听者、第三人、关键物件、接触点等；比较它们能传递什么不同的信息。一个 P 可有多个先后或同步的观看节点，依据 P4 已有表演选择，不创造额外剧情动作。
3. 明确与观看节点同步的原文发言、关键剧情声及声音连续性；标出应当看见的反应触发、信息揭示和动作结果。先考虑观众需要看到什么，暂不确定画内外声、切点、景别、机位、运镜、Shot ID 或具体秒数。
4. 以 P 为单位记录表达重点、观看对象与可见可听事件，顺读整场形成观看路径，保存 D1 工作结果。下表是 D1 识别观看价值、D3 选择摄影方案的共同参照，镜头实施由 D3 根据对白估时和整场观看路径统一决定。

## 表演或戏剧变化与镜头设计

下列是从表演推导观看重点的候选方法，按具体事件选择与组合，不是逐项执行或逐 P 切镜的配额。

| 表演或戏剧变化 | 可考虑的镜头设计 |
| --- | --- |
| 人物开始表达重要信息 | 聚焦说话者 |
| 信息对听者产生冲击 | 切向听者反应 |
| 言语涉及关键物件 | 展示相关物件 |
| 旁观者态度发生变化 | 切入旁观者反应 |
| 人物隐藏真实意图 | 捕捉微表情、视线或肢体细节 |
| 人物关系或权力发生变化 | 调整双人构图、机位或景别 |
| 人物发现新的信息 | 视线引导、主观镜头、移焦 |
| 动作即将爆发 | 强化蓄力、动作起势或对手反应 |
| 动作产生关键结果 | 展示接触、受力及环境反馈 |
| 双方处于持续肢体接触或对抗 | 交替观察施力者、承受者、接触点，或以同框看清力的关系 |
| 连续表演具有强烈沉浸感 | 保持同镜，利用镜内调度表现 |

## 对白与反应的连续表达

同一人物的连续发言包含多个 P 时，逐 P 判断说话意图及现场反应是否改变观看任务；标出信息何时影响听者、何时显出关键动作，以及原发言如何自然连续。D3 可以在句中换镜，原说话者转为场内画外声，保留语速、重音与气口。

例如血侍呈贡：先看呈贡手势，发言尚未结束便切到被献者，随后看掌权者如何接收请求；双方锁喉对峙时，观察威胁、承受者的真实反应与已有接触动作。若同框能清楚呈现双方的同步攻防，也可用连续镜头承担。依据已设计的表演选择，不提前暴露后续动作或虚构反应来凑切点。

在关键节点比较不同观看对象实际呈现的变化：谁值得被看见、什么信息获得或丢失。将具体观看需要交给 D3，而不提前决定镜头数量。完整应用见[破晓之刺镜头案例](../../examples/dawn-assassination-shots.md)。
