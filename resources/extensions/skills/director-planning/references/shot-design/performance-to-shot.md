# D1｜从表演到镜头：观看节点

核心判断：**不是发生一个动作就换镜头，而是观众此刻需要以新的方式看到什么。**

1. 顺着完整表演阅读，不先套镜头组。找出改变观看需求的节点：行动或反应、信息揭示与隐瞒、情绪或权力关系转折、空间位置或运动方向变化、关键物件因果。节点是候选观察位置，不是切点清单。
2. 对每个节点提出具体观看任务：看谁的什么变化？要同时看两人关系，还是单独看一个反应？希望观众先知道还是后知道？目前构图、距离、角度能否充分看见？
3. 比较三种决定，选择最能表达而不重复的方案：
   - **保持镜头**：同一位置能看懂连续动作、双方关系或同场反应；不打断有意义的表演连续性。
   - **镜内改变观看**：通过走位、运镜、重构图或焦点转移，令注意转移而保留时间和空间连续。
   - **切新镜头**：现有观看条件不足或有意改变叙事体验（揭示、反应、主观、对比、时间/空间转场）。切点取决于观看收益与剪辑意图，可在动作前、进行中或结果后；不把反应或新动作自动等同于切镜。
4. 比较必要镜头与可省视角。保留最能传递叙事的组织，避免重复观众已经理解的信息；可以一个节点多个视点，也可以一个镜头承载多个节点。正反打仍是不同 Shot，但可承载同一连续表演/发言。
5. 顺着拟定顺序回看，检查信息出现的时刻与人物关系是否符合意图。选择已成立的切点后进入 D2 的物理摄影与剪辑表达；切换后不重新发明动作。

## 比较切前与切后的观看结果

遇到关键揭示、关系转折或相邻镜头疑似重复时，用同一段表演试排两种观看顺序。对每个候选切点核对三个问题：

1. 切前观众已经看见了什么，正在等待或误以为什么？
2. 切后靠谁的反应、什么细节或什么声音改变了观众的判断？若仍暂缓揭示，等待是否增加了压力？
3. 留在原镜能否同样清楚地呈现变化？换视角是否牺牲了同时发生的关系、动作连续性或悬念？

例如同一段对话可先给说话人，再切听者处理后果；也可先让观众看到听者突然停手，再补出导致他停手的细节。两种画面编排对同一表演给出不同的因果体验。若候选镜头只把已经理解的表情拍得更大，可考虑在原镜中调整注意力或把切点移到真实变化发生处。

例：艾琳睁眼、侍从惊讶。若同一双人构图已清楚看到两者，留在同一镜头也成立；若侍从惊惧是主角夺回主动的揭示，可从艾琳的睁眼切入侍从反应。后面物件下落、人物接住等视觉动作可用连续动作或必要细节来表达，保持因果方向。

例：李厚肩颤、嘴角扬起、抬头笑，连续推近足以承载反转；众人惊恐是新的戏剧关系，需要看全体或特定反应时才切。切镜不取消仍在持续的笑声。这里不存在“每个动作一个 Shot”的要求。
