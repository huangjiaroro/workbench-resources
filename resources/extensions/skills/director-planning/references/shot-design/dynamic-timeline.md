# D3｜镜头内部动态时间

以 D1/D2 的观看顺序、完整表演及物理镜头为依据，安排真实能够发生的动态过程。时间是设计推导结果，不是预置 Shot 长度。

## 先安排表演，再量时间

从每个 Shot 进入状态开始，明确能看到/听到的动作、发言、反应、环境变化与摄影运动的先后和并行关系。根据是否需要等待、观众能否识别、动作是否自然、人物对话及表演节拍选择时长。必要的发言、静默和不能重叠的动作分别有时间容量；同步表演共享时间，不机械累加。

在内部实际发生有意义的变化、镜头运动开始/结束、发声或反应改变时划分时间段。复杂快速动作可使用 0.5 秒或更细的合理估计；简单凝视、整体推进等可只写一个时段。不等间隔切片；不强制凑满每秒；时间戳不是生成模型精确执行的保证。所有时段应是可读的连续局部区间，明确发生内容及持续性；镜内变化不等于硬切。必要时写同时事件和跨镜声音承接。

例如同一连续战斗 Shot 的局部 0–0.5s 为角色踏地并开始旋身、碎石扬起；0.5–1.4s 武器横扫、能量沿刀锋冲出，摄影机跟随；1.4–2.0s 能量抵达对手所在区域，后续镜头按已设计的接触反应承接。三个时间段仍是同一个 Shot；只在 D1 决定需要新观看位置时切镜。此为格式示意，不代表每个动作应使用相同用时。

## 按观看任务判断停留

按正常播放顺序读过实际动作与声音，找出观众第一次看清关键信息的位置，再判断余下的停留是否仍在积累情绪、等待结果或改变人物关系。用下面的问题调整时序，必要时回 D1 调整切点或观看方式。

| 观看任务 | 何时可以切 | 什么时候多留 |
| --- | --- | --- |
| 突发或连续动作 | 起因与动作方向已清楚，下镜能接住接触或后果 | 受力、落点或人物选择要在当前视角里才能看清 |
| 反应与喜剧落点 | 观众已看清人物态度变化，后续只重复同一表情 | 反应由忍住到失态，或短暂停顿仍在积累预期 |
| 道具与线索揭示 | 观众已定位关键细节，并理解它对当前行动的意义 | 还需辨认文字、比较两处痕迹或观察道具状态变化 |
| 空间建立或多人调度 | 下一个动作所需的出入口、人物方位和行动方向已经清楚 | 走位正在改变围堵、追逐或交锋的关系，连续观看更容易理解 |
| 对话、悬念与情绪余韵 | 当前表演已兑现观看任务，可切向承受后果的人，必要时让声音延续 | 同框仍在呈现攻防，或沉默正在形成压力、误判与等待 |

将相邻镜头连起来看。若连续几个镜头重复证明同一信息，考虑合并视角或提前切向后果；若揭示过快，先检查观众能否辨认信息，再决定延长、改善构图或调整前后镜头。保留剧本要求的动作和完整对白。

## 动作过程的时长参照

复杂镜头可按**准备、动作、结果、反应**逐段核对。准备只给观众理解意图所需的时间。结果如果关系到剧情，给它一个能被看清的停留。反应可和结果重叠，前提是观众仍能认出哪个变化引发了反应。长镜中有两组动作时，顺着局部时间轴检查第二组如何接住第一组的结果，以及运镜是否遮住关键瞬间。

下列区间是动作可读性的试排参考，来自分镜实践资料中的经验估计。角色动作速度、画面距离及声音重叠决定实际所需时间。

| 观看任务 | 可比较的起点 | 调整依据 |
| --- | --- | --- |
| 一个简单动作，如转头、伸手、触碰 | 约 1–2 秒 | 人物与动作对象已清楚时可以更短；需要看清意图或接触过程时留出准备。 |
| 让观众辨认动作结果 | 可先试留约 0.5–1 秒 | 简单状态改变一眼可见时可并入动作段；细节小、有遮挡或需要比较前后时延长或改善取景。 |
| 独立反应 | 约 1–2.5 秒 | 瞬时惊讶可能很短；压住反应、态度转变或多人先后反应可按过程延长。 |

以上区间可以重叠，也可以由同一连续镜头承载。发声、表演和观看时间按实际关系组合，使用时无需把三段逐项相加。

## 对白发声依据

取得完整实际发言（锁定 Script），区分发言、气口、反应和动作。已有对应版本且适用的真实录音，采用实际时长；否则取得可复算估计并按所选表演语速确定。中文首次估时或对白改变时实际运行技能根目录下的脚本（Node.js，单个字符串参数；按顺序输入完整纯对白，去除说话人和舞台提示）：

```bash
node scripts/estimate-dialogue.mjs "你说什么？我没有答应。"
```

脚本估计汉字与数字的发声字数/语速区间，不统计外语词、独立停顿或其他动作。外语使用适合语言的可复算方法，混合语言分别计算；记录完整发言范围、统计规则、语速、计算结果或实录、选用发声时长及额外停顿。已有准确有效结果直接复用，不对每个切分的片段重复累加估时。未经实录均标明规划估计。

发言可跨镜，Shot 各自注明原文或精准定位区间、说话者、局部声源位置与时间、持续/断开关系；合计必须覆盖完整原文。无需另建声音或台词表。动作中说话必须符合具体表演，不能把静默区段当成可用发声时间。

**长对白的画面落点。** 语义转折处可换视角，让观众重新理解说话人的意图。若关键词改变听者的判断，可在发声仍持续时切听者。台词需要物件作为证据时，可切物件状态或人物使用它的动作。说话者仍在作出关键选择，或同框能看清双方攻防时，可以继续保持原镜。按原文和实际发声标出跨镜区间，画面切换本身不增添语音停顿。声音提前进入或延续时，按[剪辑语言](editing-language.md)核对它是否改变了观众理解事件的顺序。

## 时间汇总

将各 Shot 局部 0 起点时轴及自然时长用于全场顺序和全集求和。跨场连续镜头只登记一次，标注覆盖段落。若时间或表演无法成立，回 D1–D2 调整有效观看组织或回 P 调整表演。用户明确要求的总时长是创作约束；无法同时满足原文时交主创协调。按具体观看任务和表演推导时长，无明确要求时不设全片或镜头的默认时长。
