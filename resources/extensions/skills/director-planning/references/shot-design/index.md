# 镜头设计执行索引

输入：锁定 Script、有效 director-plan 与 performance-plan。逐场连续设计。

| 步骤 | 输入与依赖 | 方法 | 内部设计结果 |
| --- | --- | --- | --- |
| D1 观看节点与镜头切分 | 完整表演、A1 表达重点、A3 空间关系 | [表演到镜头](performance-to-shot.md) | 观众观看任务、保持同镜/镜内转移/切镜的决定和切点、拟定 Shot 顺序与覆盖 |
| D2 摄影与剪辑表达 | D1、总体视觉与空间基准、表演状态 | [电影镜头语言](cinematic-language.md)、[剪辑语言](editing-language.md)；按需风格案例 | 各 Shot 景别、机位、方向、构图、运镜及连接关系 |
| D3 动态时间轴 | D1/D2、对应完整表演与原文发声 | [动态时序](dynamic-timeline.md)，安排动作与发声容量；动作过密或结果难辨时查[动作时长参照](dynamic-timeline.md#动作过程的时长参照)，长对白查发声与跨镜画面落点 | 各 Shot 内部相对时间、动作/声音/摄影的先后与并行、自然时长及整集规划时长 |
| D4 覆盖与连续性校验 | D1–D3、Script、director-plan、performance-plan | [完整性检查](coverage-validation.md)、[计划连续性](../continuity/continuity.md) | 原文覆盖、观看逻辑、容量与状态均成立的镜头方案 |

D1 决定观看方式与切点，D2 负责实现与连接。若摄影实现无法满足观看需求，回 D1 校准；D3 若发现表演或声音容量不足，检查具体表演及 D1/D2 设计，不以固定时长倒推方案。D4 定位问题并返回产生该问题的步骤；涉及完整表演或总体基准时先同步对应上游成果。

当同一表演可留在全景或切反应镜、需要比较观众先看见什么，或必须让一句对白自然跨镜时，参照[祠堂狂笑镜头案例](examples/ancestral-hall-shots.md)。案例沿用同一套表演节点，比较两种观看方案，并示范 D1–D4 如何从选择推到具体切点、时长与连续性检查。

按 [镜头规划模板](../../assets/shot-plan-template.md) 交付 `shot-plan.md`，供视频制作和背景音乐规划承接。
