# D4｜覆盖、容量与连续性检查

终稿从剧本向表演、再向 Shot 双向核对。此处验证已设计内容，不重新设立镜头数量、时长或切点规则。

- **原文保真**：按 Scene 核对全部剧情事件、关键动作、对白原文和说话者、信息揭示。用原文位置、表演节点、Shot ID 定位。没有被拍到的过程须仍通过设计中的声音或其他合法表达让内容完整成立；不可无故丢弃。
- **表演覆盖**：各 Shot 组合兑现完整表演与必要反应。跨镜动作和发言顺序真实、前后衔接，不重复演出或漏掉因果环节。不存在镜头组只能看见抽象情绪的情况。
- **观看连贯**：复核 D1 已确定的观看任务是否落实；按 [剪辑语言](editing-language.md) 检查连接，尤其关系轴、视线、屏幕方向、接触动作、信息释放时机。
- **时间容量**：局部区间落在 Shot 内、时间顺序、重叠关系明确。使用 D3 完整发声依据验证发言可演；确认必要动作和停顿不被压缩。总时长由唯一 Shot 明细重新求和。没有隐藏无效静默用于补足秒数。
- **观看节奏**：按场次顺读镜头和时序，使用 [D3 观看任务判断](dynamic-timeline.md#按观看任务判断停留) 检查信息是否来得及辨认、切点是否拖到表演变化结束以后。重点复查停顿、重复反应和长时间停留是否仍有戏剧作用，定位到实际 Shot 及区间。
- **状态连续**：按 [计划连续性](../continuity/continuity.md) 比较相邻镜头出入状态，重要资产、人物、手别、站位、道具、伤损、光源与环境有依据。计划不等于实际生成状态。
- **交付**：记录依据版本、未决项、所需资产，清楚标示实际覆盖和必要声音；技术模型限制交制作人处理。局部改变先修改其权威上游再同步 Shot；无需另建验证文件。

## 整场顺读时看三条变化

按播放顺序对照**情节推进、情绪强度、切镜密度**。例如安静的质问可以让情节变化少、情绪压力持续升高，镜头保持同框直到听者真的改变策略。揭示已看清后，若几个反应镜只重复同一种情绪，可试合并视角，把时间留给真正改变关系的反应。若快切使原因和结果黏在一起，先给观众看清关键变化的时间，再比较保留同镜还是重新安排切点。最后从原文和 P 节点回查，确认节奏调整保留了完整动作、对白和声音的承接。
