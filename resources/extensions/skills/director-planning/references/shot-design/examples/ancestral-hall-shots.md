# 祠堂狂笑｜用同一段表演比较两种拍法

承接[祠堂狂笑表演案例](../../performance-design/examples/ancestral-hall-performance.md)中的原文 ①–④、空间基准和 P001–P006。两种方案共用同一表演、原文和发声，比较观众注意力的分配。下列镜头是按[镜头规划模板](../../../assets/shot-plan-template.md)展开的教学示例，时间为规划估计。

## D1 比较观看方案

| 观看点 | 方案 A　全景保留反应 | 方案 B　切出李宝的反应 |
| --- | --- | --- |
| P001–P002，察觉李厚的异常 | 两案均连续推近，观众先看出肩颤和笑意，再听清压抑的短笑。 | 同左。 |
| P003–P004，看到狂笑改变局势 | 在狂笑爆发时切全景，镜内从李厚和供案转向围攻者，保留李宝后缩、李父失衡与全场位置的关系。 | 同样先切全景建立因果。看到李宝转头并开始后缩后，切近景接住躲到母亲背后的后半个动作，笑声继续。 |
| P005–P006，听到李父夺回话语权的尝试 | 两案都切李父，看到他站稳、开口。说到祖宗牌位后，画面切回李厚，听完李父的整句指责。 | 同左。 |

全景中如果李宝的动作清楚可辨，方案 A 能让观众一次看懂整个包围圈的松动。若本段要突出他由围攻者变成向母亲寻求庇护的喜剧反差，方案 B 用近景单独交代这个变化。以下展开方案 B。若试排发现全景已足够突出他的转变，可把 S002 与 S003 的观看范围合回一个全景，此时仍从同一条表演时间线继承动作与声音。

## D2–D3 摄影与镜内时间轴

**空间基准**　摄影机均在李厚与李父的南北关系轴东侧。供案在李厚北侧。李父后退向南，李宝从李母东侧绕到她身后。切换视角时继续使用这些世界空间位置。

**发声依据**　用[中文对白估时脚本](../../../scripts/estimate-dialogue.mjs)输入李父的完整原话，得出 14 字。自然对白估计为 3.1–4.0 秒，4.0 字/秒约 3.5 秒。本例分配约 3.6 秒净发声，另留 0.3 秒气口和 0.6 秒稳杖动作。拟声的具体长短由短笑、转为狂笑和收尾的表演决定，末段笑声连续跨镜。

### S001｜异常的笑意，2.6 秒

- **覆盖与观看目的**　P001–P002、原文 ①与②前半。持续看李厚由安静到压不住笑的变化。
- **摄影**　从李厚东南侧、略低于胸高的中近景缓推，开头纳入肩与下垂的面孔，结束时看清嘴角与逐渐抬起的脸。

| 镜内区间 | 动态表演、剧情声音与摄影变化 |
| --- | --- |
| 0.0–0.8 秒 | 李厚低头站定，双肩开始轻颤，围攻声继续，镜头渐近。 |
| 0.8–1.7 秒 | 嘴角扬起，发出「噗……呵……」，摄影机继续推向面部。 |
| 1.7–2.6 秒 | 缓缓抬头，短笑「哈哈……」逐渐放大，构图收至脸和肩。 |

- **状态与切点**　李厚双脚未动，头已开始抬起。下一镜接住仰头爆发，扩大观看范围让全场变化可见。

### S002｜狂笑震动祠堂，2.4 秒

- **覆盖与观看目的**　P003、P004 起势，原文 ②后半与③。让观众看见狂笑与供案、围攻者之间的因果。
- **摄影**　关系轴东侧的低位全景，略向北取景，将李厚、北侧供案和南面围攻者纳入同一构图。机位固定，由发声和环境动势带动注意转移。

| 镜内区间 | 动态表演、剧情声音与摄影变化 |
| --- | --- |
| 0.0–0.5 秒 | 承接上一镜的抬头，李厚猛然仰头，开始放声大笑「哈哈哈哈哈哈！」。这次发声延续到后续镜头。 |
| 0.5–1.4 秒 | 狂笑持续，牌位从静止转为振动并歪斜，香炉发出嗡鸣。 |
| 1.4–2.4 秒 | 笑声与香炉声持续。李宝先转眼看供案，再开始后缩。李父失衡向南退半步，右手对拐杖的握力松了一下。 |

- **状态与切点**　牌位歪斜，李父已经退到新位置，杖仍接触右手。切在李宝已开始后撤时，下一镜继续这一步。

### S003｜李宝躲到母亲身后，1.4 秒

- **覆盖与观看目的**　P004 后半。用李宝从参与围攻到寻求庇护的具体变化落下笑点。
- **摄影**　轴东侧的近景，镜头贴近李宝视高，保留李母肩侧作为位置参照。起幅看见李宝已缩肩，结束时李母挡住他大半身体。

| 镜内区间 | 动态表演、剧情声音与摄影变化 |
| --- | --- |
| 0.0–0.8 秒 | 李宝沿李母身侧完成后撤，躲到她身后。李厚的笑声作为同场画外声延续。 |
| 0.8–1.4 秒 | 李宝停在李母背后，仍留意李厚。给观众时间看懂他在借李母遮挡。笑声开始回落，香炉声仍有余振。 |

- **状态与切点**　李宝留在遮挡后，李父已在退后的站位。切向李父，看到另一种反应。

### S004｜李父重新开口，3.7 秒

- **覆盖与观看目的**　P005 与 P006 前段、原文 ④前段。让观众看见李父如何把失衡掩成威严。
- **摄影**　轴东侧、位于李父东北面的中近景，约胸高，构图同时带到脸和右手拐杖。李父持续朝北看李厚。

| 镜内区间 | 动态表演、剧情声音与摄影变化 |
| --- | --- |
| 0.0–0.6 秒 | 李父在已退后的站位重新握稳拐杖，抬眼。李厚的笑声在这段收尾。 |
| 0.6–1.6 秒 | 李父提高声音说「大逆不道！」，右手仍握杖。 |
| 1.6–1.9 秒 | 短气口，视线仍盯着李厚。 |
| 1.9–3.7 秒 | 李父接着说「你当着祖宗牌位」，发声延续至下一镜。 |

- **状态与切点**　切画面时李父正在质问，保持同一次发声。把视角移向受到斥责的李厚，让观众看这句话对他有没有作用。

### S005｜斥责落到李厚身上，1.2 秒

- **覆盖与观看目的**　P006 后段、原文 ④尾段。观察李厚如何接住这句质问。
- **摄影**　回到李厚东南侧的近景，构图保持他的目光朝向李父，固定机位留住余笑。

| 镜内区间 | 动态表演、剧情声音与摄影变化 |
| --- | --- |
| 0.0–0.8 秒 | 李厚把视线落向李父，脸上余笑仍在。李父画外连说「笑什么？！」，与 S004 接成完整一句。 |
| 0.8–1.2 秒 | 李厚保持沉默，让观众读清斥责没有使他退让。香炉只剩余振。 |

- **离开状态**　李厚始终在堂心，李父留在退后的站位且右手拄杖，李宝仍在李母背后，牌位维持歪斜。

## D4 覆盖、容量与节奏复查

- **原文与表演覆盖**　S001 保留肩颤和短笑，S002 完成仰头狂笑与环境变化，S003 接续李宝的同一次后撤，S004–S005 承接李父稳杖与完整对白。P003/P004 的重叠用连续笑声和全景中的表演表达，李父退步只发生在 S002。
- **对白容量**　李父的净发声为 1.0 + 1.8 + 0.8 = 3.6 秒。气口和稳杖分别留在 S004。S004 与 S005 连续拼合为「大逆不道！你当着祖宗牌位笑什么？！」，镜头切换处没有额外停顿。
- **节奏取舍**　顺读全场，先辨认异常，再看影响范围，最后理解围攻者的不同反应。若全景里已经能认出李宝在借母亲的身体遮挡，S003 缩短或与 S002 合并都可能成立。若近景尚未看懂就切走，应先检查肩侧遮挡和构图，再决定加多少停留。
- **时长与连续性**　方案 B 的五镜合计 2.6 + 2.4 + 1.4 + 3.7 + 1.2 = **11.3 秒**。方案 A 若保持这版表演时序，可用一个 3.8 秒的全景承接 S002–S003 的动作和声音。两案都保留笑声连续性、右手拐杖、李父后移和牌位歪斜。
