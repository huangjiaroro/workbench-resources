# 场景俯视调度图与机位关系

结合[场面调度](blocking-and-staging.md)建立可共享的空间基准，与镜头阶段的轴线及覆盖、本技能的计划连续性相互核对。具体交付按[导演技能入口](../../SKILL.md)执行。

## 什么时候必须建立场景图

当场景存在多人互动、复杂走位、道具交接或容易产生方位歧义时，在导演总体方案建立**可阅读的俯视空间基准**（ASCII 图或等价简图均可）。简单空间可用文字说明。

## 空间基准与标记

- 标明场景 ID、视图方向（如纸面向上为北）、固定地标：门、窗、墙、主要家具及出入口。不要每个 Shot 重画或改变房间。
- 总体规划标明角色初始世界空间位置、身体朝向、关系轴及移动条件。
- 表演设计在空间基准上确定路径、位置变化、目光及关系轴改变，记录相应表演节点。
- 镜头设计依据真实站位推导摄影机区域与观察方向，按需引用机位符号（如 `CAM-A`），注明控制屏幕方向所需的状态。区分角色左右、世界方位与画面左右。
- 正式素材只从资产登记簿引用；图是空间安排，不冒充已经生成的场景图片或实际关键帧。

## 最小示意（表达方式不限定）

```text
                         北 / 墙面
   西窗 ┌──────────────────────────────┐ 东门
        │    沙发      矮凳/水盆        │
        │   雷克萨 ↑   希拉 ↖          │
        │                              │
        │    CAM-A →       CAM-B ↗     │
        └────────入口───────────────────┘
   初始：雷克萨坐在沙发；希拉站在沙发东南侧。
   P002：希拉后退碰到矮凳；水盆部分水洒出但没有翻倒。
   S21（CAM-A）：希拉拍开扶腰的手；雷克萨手撤回。
   S22（CAM-B）：水盆溅水；承接 P002 的盆位置与水量。
```

以上仅演示标注方法，**不是 EP04 的锁定真实场景布局**；导演必须按实际剧本和已确认场景资产确定布局。

## 镜头与覆盖设计引用

每个 Shot 至少能从场景图或紧邻文字识别：`scene_id`、机位区域/朝向、可见人物、人物屏幕左右/视线、起止状态。允许简洁自然语言；没有必要强制 YAML、坐标小数、固定编号表或脚本解析格式。每次空间变化需要一条可追踪的调度事件，不能让人物或道具靠镜头切换瞬移。

## 检查时应区分

- **真实矛盾**：同一连续时刻，一张图门在东面，下一镜无解释地跑到西面；人物无移动而换到关系轴另一侧。
- **需要说明的变化**：人物实际换位、摄影机有意越轴、关系轴因第三人加入发生变化；允许，但要说明画面如何让观众理解。
- **证据不足**：机位或人物方位未写清，不能据此宣称“空间检查通过”；负责人要求定点补充即可。
