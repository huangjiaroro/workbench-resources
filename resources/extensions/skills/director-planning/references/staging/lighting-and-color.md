# 灯光、色彩与空间一致性

用于决定场景光源、色彩效果及其在镜头之间的衔接。

## 核心原则：先确定真实世界光源

写清楚场景中是什么照明：窗外日光、油灯、蜡烛、火堆、月光、壁灯或反射光；光从何处照到人物，是什么色温与软硬、阴影如何落在地面和脸上。避免只用“暖色、电影感、戏剧性”作为摄影规划。

| 光 | 导演用途 | 空间关系 |
|---|---|---|
| 主光 Key | 人脸与物件的主要明暗塑形 | 明确固定世界方位与高度 |
| 补光 Fill | 决定阴影细节与主次对比 | 不应突然把同一人物换成另一个光比 |
| 轮廓光 Rim | 分离主体与背景 | 检查它能否被场景内真实光源解释 |
| 眼神光 | 强化人物表情的可读性 | 与主光或空间照明保持可理解的一致关系 |

## 人物关系与对比

同框的两个人处在同一个照明空间，可以拥有不同光比，但不能在反打时各自获得互相矛盾的独立光源。权力关系改变时，可以通过人物走进或离开光区，让表演而非突兀的灯光重置表达变化。

- **硬光**：清晰阴影边界，适合明确压迫感、空间深度或正午太阳、裸灯。
- **软光**：影缘缓慢过渡，适合窗漫反射、阴天、布幔光或柔和表演。
- **高反差**：使部分信息被隐去；不要让故事证据因此不可辨认。
- **低反差**：开放、平静或刻意无处躲藏；也可能减弱戏剧压力。

## 色彩与美术

设定**全场稳定的主色、辅助色与强调色**。色彩变化应由光源、天气、时间、实际场景状态或明确的叙事转换触发。同一时刻，同一光源的方向和色温不因摄影机切到反打自动改变。

## 时间变化

日出、正午、黄昏、夜晚的太阳高度、影子长度、窗外色温不同。同一连续场景不应无理由从正午投影变成黄昏逆光；如果有时间跳跃，需借助画面或声音让观众理解。

## 交接

导演在 `director-plan` 产物中定世界光源，Shot 中写明对当前机位与人物的实际照明方向。制作人依据正式场景和角色资产在当前模型模式中实现；照明 Prompt 与模型参数由视频制作方法维护。
