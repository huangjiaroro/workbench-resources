# 视听具象化

以 Script 的动作、原话与事件结果和编剧设计为依据。区分文学描述、真实故事事实及表演可执行信息。形容词与比喻可帮助理解气质，但不能替代可观察事件。

1. 找出原文要求观众实际感知的内容：发生的事、态度、力度、环境变化与他人反应。已可直接表演的内容保留。
2. 对抽象或不可表演的词补充具体外显变化：身体姿态、视线、嘴部、呼吸、手脚动作、发声、接触、环境反馈。选择足以表现意图的少量决定，而非机械穷举人体细节。
3. 区分夸饰和世界观内的真实效果。若作品明确牌位被笑声震歪，就设计其确实发生的变化；若只是“目光如刀”，无需让眼睛真的射刀。按既有风格保留夸张喜剧与奇幻力度。
4. 将省略但必须发生的过渡补全，确保表演从当前状态自然到下一状态；不额外创造剧情事实、改变原文因果或增删对白。

## 让情绪变化有可见依据

选取情绪真正变化的地方，依次找出**原先在做什么、刺激是什么、如何应对、最后留下什么变化**。隐忍场面可从原有行为被打断入手，例如角色一直在整理桌面，听到触及秘密的名字时手停了一下，随后按原顺序继续整理。停手和继续各有含义，前者暴露在意，后者说明仍在掩饰。若原文要求骤然爆发，保留突然性，只补足让观众辨认其触发和后果的行为。按实际场面选择必要变化。

例：李厚“排山倒海般狂笑”，落实为低头与肩颤、压抑笑声逐渐逸出、嘴角扬起、抬头放声大笑；牌位歪斜、香炉震颤、围攻者由责骂转为噤声和退缩。不是只改为“很大声地笑”，也不提前要求特写或反打。
