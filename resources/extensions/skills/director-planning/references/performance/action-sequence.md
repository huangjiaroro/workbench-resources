# 完整表演过程与状态

按原场次从入口状态连续排演至出口状态。以 P2 的表演推进为主要骨架，整合 P1 的视听事件、P3 的移动与空间调度，并承接前场离开状态。P4 的单位是表演节拍（Performance Beat）：连续表演中具有统一行动／语言意图及可辨认表演过程的段落。

1. 建立当前人物位置、朝向、可接触物件、手中物、环境和注意对象；继承导演方案的空间图与前场结果。
2. 依据已设计的表演推进识别节拍，使用下方「节拍边界与颗粒度」判断拆分与保留。先设计表演，再决定边界，而非按标点、人物或微动作逐项拆分。每段填写行动／语言意图及实际表演过程，包含起因、实施和结果所需的细节。
3. 将原文对白按其实际发生的节拍分配到独立对白列，注明说话人；落实 [P2 长对白拆分规范](acting-direction.md#连续对白的表演推进与节拍拆分) 中设计的表演变化。一段发言可以连续跨越几个 P，连续发言的片段按原文精确衔接。写清动作、声音、听者反应的触发和同步关系，真正同时发生的表演放在同一段落中。无对白写 —。
4. 更新段末需要后继继承的实际状态：位置、朝向、持物及手别、姿态、接触关系、外观伤损、光色、环境等；无变化写 —。以状态差量为主，继承未变化的事实。参见 [计划连续性](../continuity/continuity.md)。
5. 独立回读实际表演稿、有效设计依据、剧本原文及空间、状态依据。按核验范围从进入状态连续复排至离开状态，逐段核对原文事件与对白、节拍质量、触发与同步关系、状态继承。将分段对白按照发生顺序拼回完整原话；检查说话人、连续发言与停顿关系。按下方「节拍质量检查」修正过粗、过碎或错误串行的段落，仍有长节拍则确认其表演依据；回到对应设计修正并同步 P4，重新读取并复查受影响段落及其前后状态。若场面矛盾无法通过表演解决，找主创协调编剧。

## 节拍边界与颗粒度

一个 P 承载相对完整、具有明确表达意义的表演节拍。判断边界时，关注当前行为的目的、推进与结果是否发生值得独立表达的变化，而非动作数、句子数或人物数。

| 变化类型 | 示例 | 编排判断 |
| --- | --- | --- |
| 行动意图或策略变化 | 审视→威胁→攻击 | 形成新节拍 |
| 语言意图或关键信息变化 | 陈述→质问→嘲讽；交代隐疾→指认真凶 | 按实际表演推进拆分 |
| 关键情绪或互动转折 | 恐惧转为杀意；被质问者决定反击 | 在触发与变化处形成新节拍 |
| 动作因果与结果变化 | 发起攻击→对方成功格挡→借势反击 | 按独立攻防目的与结果拆分，相互接触的瞬间连续衔接 |
| 同一行动的连续动作细节 | 左脚踏地→转腰→横扫 | 可保留于同一 P，写清准备、发力及结果 |
| 附属表演和同步反馈 | 说话时握拳；威胁时听者下意识后缩 | 融入触发它的表演节拍；反馈若引发新的行动策略再拆分 |

先判断实际表演变化，再应用长对白字数检查。短对白、无对白同样可能包含多个节拍；较长的统一行为可以保持完整。并行行为可共享一个 P，不强制一个角色一个 P。P 不由未来镜头数量、景别、运镜或预计 Clip 长度决定。

若相邻两段的边界只来自微动作而没有独立意义，优先合并；若一段包含先后发生的多个独立意图或有各自结果的行为，优先拆分。拆分后仍继承动作、声线、姿势与实时互动，不凭空增加停顿。

## 从表演推进到表演节拍

例如 P2 已确定血侍「请示时躬身 → 介绍时侧身示意 → 恭请时恢复行礼」，则 P4 可把原话分配为「禀告裁判长大人，」「这是黑市最新呈送的纯血贡品，」「请大人享用头啖之血。」三段；将艾芙琳的持续示弱及加布里埃尔的同步审视放入对应节拍。它们属于同一次发言，段落边界本身不是停顿。如果实际表演不中断且没有重要变化，也可以作为一个段落。完整示例见 [破晓之刺表演案例](../../examples/dawn-assassination-performance.md)。

## 多人反应的并行编排

从共同事件出发，逐人确定反应条件。有人直接看到变化，有人只听到声音，有人通过另一人的动作才察觉。先排直接反应，再排因他人反应触发的后续，最后把继续发生的对白、环境声和角色原有动作放回同一过程。可以同时响应同一刺激，也可以故意齐动形成喜剧效果。若各自有不同的判断和意图，就给他们不同的起势或反应次序。

## 复排时定位缺口

从入口顺读一遍，在关键节点问三件事：人物此时知道什么，身体或物件能否从现有位置完成这个动作，观众能否从行为理解关系变化。人物若提前演出稍后才知道的结果，回到该人物的刺激与反应重排。多人互相等待、关键动作缺前因或道具突然换手时，回到对应节点补齐触发、并行关系或状态承接，再同步离开状态。

例如动作片中，对方受惊→主角启动→对方作出防御反应→物件发生位置变化→双方形成新状态；按表演节拍推进，留给 D 决定镜头组织与具体秒数。

## 节拍质量检查

- **过粗：** 一个 P 是否囊括多个先后发生的独立意图、攻防转换或关键结果？将真正改变表演方向的部分分段。
- **过碎：** 相邻 P 是否只是同一行动的准备、动作细节或伴随表情？合并没有独立表达意义的段落，保留可执行细节。
- **对白：** 按 P2 字数规则检查连续发言，尤其超过 20 字者；核对内部语言、信息、情绪及互动的变化是否已经落实，连续原话能否无损拼回。
- **互动与时序：** 听者反应是否有触发依据、发生在正确词句或动作处？真正并行的动作、对白及环境反馈是否被误排成先后？检查独立反击或策略改变是否有完整的因果承接。
- **状态：** 每段结果是否在后段真实继承；所有关键动作、对白与结果是否完整覆盖。

只修正实际发现的问题，不为追求统一颗粒度增加 P 数量或删去原文。
