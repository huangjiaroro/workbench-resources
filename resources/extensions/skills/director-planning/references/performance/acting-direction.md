# 人物表演设计

读取编剧已经定下的目标、阻碍、潜台词及人物关系。面向完整场次设计可演的行动、对白和反应；将下列三个部分记录在 P1–P3 表演设计依据的 P2 列中，为 P4 提供表演推进骨架。

## 行动目标

明确此刻谁试图对谁或对什么达成什么目的。把人物总体目标落在当前行动上：迫使对方服从、试探真假、掩饰身份、诱导对方靠近、转移注意、争取时间等。区分外在表现与真实意图，例如故意示弱其实是诱敌；遵循角色此时已知的信息。目标可通过行动或沉默实现，不必给每个动作另造心理动机。

## 表演推进

围绕人物目标，顺着行动及对白设计策略、语言行为和身体表演的推进。语言行为关注说话者在做什么（命令、请示、质问、威胁、说服、掩饰、应允等），以及何时改变方式。找出语义、重音、动作或对方反应中真正引发表演改变的位置，并选择可见、可听的行为。先设计这些变化，再划分节拍；一段持续有效的表演也可以保持完整。

按实际发生顺序组织表演推进：人物正在做什么、受到什么刺激、采用何种行为或语言策略、产生什么可观察的变化，以及这个结果如何引发下一步。关键交锋应具体到相应词句、动作或信息揭示，让 P4 能辨认节拍边界。动作内部的发力、姿态、表情等细节可共同支撑同一个表演目的，不必逐项编号。沉默、克制和维持现状同样是表演选择。

- **身体、视线、表情**：姿态朝向、重心与距离、注意对象、面部张力和表情改变的过程；避免只有“生气、害怕、悲伤”等标签。目光和动作应有对象。
- **言语表演**：原话与说话人不变，按情境给出必要语速、声线、气息、重音、犹豫、停顿或打断；发言动作与听者反应可同步。已有角色音色身份引用登记信息。
- **互动**：一个人发言或动作如何影响另一人；听者可能掩饰、迟疑、反击或先于对方完成反应。强调发生改变的节点，不给每句对白配同等夸张动作。
- **层次与反差**：一个可辨认的主要表演动作加必要支撑细节；保持角色特有的身体语言。静止、等待、迟来的反应也可有表演意义。喜剧可利用预期与反差、反应延迟，但不机械规定停顿时长。

## 连续对白的表演推进与节拍拆分

按一次连续发言中的汉字数（不含标点、说话人及舞台提示）触发下列设计检查。其他语言按实际发声容量类比判断；字数是表演设计的检查依据，逐 P 净发声估时由 D2 完成。

| 连续发言字数 | 处理方式 |
| --- | --- |
| 12 字以内 | 根据表演需要自然组织 |
| 13–20 字 | 分析内部语言意图、行动及互动反应变化，按需要拆分 |
| 21–32 字 | 必须分析内部表演推进，设计多个有意义的表演节拍 |
| 33 字及以上 | 必须分层组织语言行为及听者反应，落实为多个表演节拍；重点复核长时间停留 |

拆分位置优先选择以下实际变化，而非按字数等分：

- 语言意图：陈述→质问→威胁。
- 信息：交代背景→揭露真相→公布真凶。
- 情绪：平静→愤怒→失控。
- 互动反应：听者从怀疑→震惊→崩溃。
- 行动：靠近、转身、展示证据等。

目标为单节拍通常不超过 20 字；确有价值的连续表演可保留并说明原因。连续发言仍是原说话人的完整原话，节拍边界不意味着增加停顿、改词或切镜。具体变化写入 P2 表演推进与互动反应，交 P4 落实为逐段表演及对白。

## 互动反应

对承重交锋，先找出哪一个词、动作或沉默会让对方改变判断。给听者安排当时已经在做的事、注意对象和触发后的变化。反应可以出现在句中，也可以在对方说完后才显露，取决于听者何时明白、是否想让对方看出来。若角色一边说「你继续」，一边把正在递出的钥匙往回收，手的变化可成为听者真正需要回应的信息。停顿可以用等待答复、观察反应或压住脱口而出的话来承载。无须给每句台词安排手势。

区分伴随反应与独立推进：听者在指控过程中握紧刀柄，可与指控同时编排；若他随即改变策略、开口驳斥或发动攻击，则按实际触发形成下一表演节拍。多人可以同时拥有不同意图，不因说话人以外的角色有动作就强制串行拆分。

例如李宝在听到五十两时由愣住转成眼睛放光、搓手前凑，仍假装关心哥哥；听到随营充军时笑容僵住，身体后缩再跪倒。表现权力与利害的反转。后续由 D 选择观看方式。

## P2 记录示范

血侍呈贡：

- **行动目标：** 血侍恭敬呈贡，艾芙琳伪装虚弱。
- **表演推进：** 血侍请示时抱拳躬身 → 介绍贡品时侧身示意 → 恭请享用时恢复行礼；同一次发言，礼貌而清晰。
- **互动反应：** 艾芙琳在呈报期间维持伏地轻颤；加布里埃尔听到恭请享用时垂眼审视，话毕沉默。

威权交锋（方法示意）：被审判者以揭露隐疾摧毁审判者的威信。表演推进为轻蔑反问→陈述具体病症→贬低其权威；互动反应为审判者最初不屑、听到隐疾时握刀收紧、旁观者因其失态转头审视，直至审判者决定出刀反击。将这些反应落实到触发它们的语言或行动上，而非在全部台词说完后才集中表现。

根据剧本与情境组织真实表演推进，而非按照标点添加动作。无对白的押送、格斗、奔跑、观察等同样适用：行动目标决定角色的行为方式，新的刺激、意图或接触结果推动表演变化。完整示范见 [破晓之刺表演案例](../../examples/dawn-assassination-performance.md)。
