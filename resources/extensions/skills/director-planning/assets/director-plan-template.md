# 导演整体方案

输入：锁定 Script、episode-design、必要 Canon/State 与登记资产（注明采用版本）。按[总体规划执行索引](../references/overall-design/index.md)完成 A1–A4。

## 全集构思

- 戏剧表达：主导情绪、权力或关系变化、观众何时掌握关键信息，重点场面的对比与节奏方向。
- 视觉表达：本集视觉论点、风格、光色及摄影总体原则，以及这些选择如何服务具体戏剧变化。

## 场次 SC01（沿用原剧本场次）

| 设计内容 | 必须落实的结果 |
| --- | --- |
| A1 戏剧节奏与表达重点 | 关键原文事件及其前后变化；人物关系、观众知情与情绪演进；何处蓄势、释放或留白，突出什么以及理由。 |
| A2 视觉定调 | 具体可见的场景基调、世界光源位置/方向、光色、影调与重要主体的视觉关系；需要变化时明确依据。 |
| A3 空间基准 | 固定地标、出入口与相互位置，人物初始站位/朝向、主要关系轴、遮挡与移动条件。复杂空间附共享俯视图，参见[场景图例](scene-map-template.md)。 |
| A4 状态和资产 | 与前后场相接的身份、服饰、持物、时间、环境及空间状态，采用资产的准确引用；缺失正式资产与对应需求。 |

逐场展开适用结果；连续不变的空间与资产可引用共同基准。总体规划保留原文事件的戏剧节奏分析，粒度以指导下一阶段为准。

## 完成判据

所有原剧本场次都有具体表达重点、可使用的视觉及空间基准；相邻场次状态变化有剧情依据；资产缺口明确，复杂走位有可复用地标。表演设计能够直接承接这些决定。具体动作序列、镜头和时序由后续阶段设计。
