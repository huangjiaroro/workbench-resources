# 镜头规划（Shot Plan）

依据：有效 Script、director-plan、performance-plan 版本及[镜头设计执行索引](../references/shot-design/index.md)。全剧集唯一 Shot ID、真实播放顺序；Scene 为原剧本场次。

## SC01｜场名

空间基准：总体方案对应场景图或文字基准；表演依据：本场表演节点。

每个 Shot 必须包含：
- **D1 覆盖与观看目的**：对应原文及表演节点范围、观众需要看到或听到的具体信息；为何在此保持连续观看或切换视角。
- **D2 摄影**：景别、机位位置/高度、方向与构图主体，必要焦距、运动轨迹、焦点及其变化；演员方位、视线和画面运动方向与空间基准相容。明确开始和结束构图。
- **D3 动态时间轴**：局部秒数范围、实际表演及摄影变化、剧情声音。同步事件在同一时段；跨镜发声标明角色、画内/画外、原话区间及延续关系。
- **D4 状态与衔接**：承接上镜的身体、空间、道具、声画状态，结束状态与下镜切点依据。复杂衔接写清匹配关系。

### S001｜自然时长 2.5s（结构示例）

- 覆盖：对应表演节点及原文；承接李厚低头站立。
- 观看目的：先察觉态度反转的征兆；保持连续观察，让笑意逐渐显露。
- 摄影：中近景，李厚侧前方、胸高偏低，等效 50 mm；从肩部及下垂面孔缓慢推近至脸；推镜不越关系轴。

| 镜内区间 | 动态表演、剧情声音与摄影变化 |
| --- | --- |
| 0.0–0.8s | 低头，双肩轻颤，嘴角开始上扬；渐近。 |
| 0.8–1.5s | 压着气发出短促笑声；保持脸部可见。 |
| 1.5–2.5s | 缓缓抬头，笑声放大，视线迎向众人；推近到结束构图。 |

- 状态/衔接：身体朝向不变，笑声延续至后镜；观众已看清笑意时切向众人反应，揭示围攻者失去主动。

按实际观看目的组织其余镜头。上述秒数、分段及摄影仅为示例；简单镜头可只用一个连续区间，复杂镜头按动作、反应和声音的实际发生节点细分。跨场连续镜头只登记一次，注明覆盖范围及区间。

## 完成判据：时间与覆盖核对（D4）

- 完整原文对白、关键动作和反应、表演节点均有可追溯画面或声音承载。跨镜对白不得丢失或重复。
- 保留必要发声依据（实录或原文、自然语速、停顿等估算依据），核对动作及发声容量。各镜时间区间从 0 到该镜结束，连续；并行事件不重复计时。
- 按[观看节奏检查](../references/shot-design/coverage-validation.md)顺读镜头。关键变化有时间看清，停顿及延长仍服务观看目的，切点有实际依据。
- 汇总各场次与全集自然时长，数值与逐镜明细一致。时长由表演和观看需要推导，不采用固定镜头数量、平均时长或技术 Clip 上限。
- 对照空间基准和表演设计检查人物方位、视线、动作及道具状态。必要调整先同步受影响的表演设计。
