# 场景俯视图（示意格式，不是强制表单）

根据场景复杂度选择 ASCII 俯视草图或带清晰锚点的文字。标出门、窗、固定家具、人物位置与朝向、必要移动目标、可拍摄区域及关系轴。实际机位与 Shot 在后续镜头设计中确定。**示例有两扇不同的门：西墙门与南侧入口，不得混称。**

```text
                        北 / 靠窗墙
        ┌───────────────────────────────┐
        │                    角色 A ↙   │  东窗
西墙门 ╱│   桌椅                        │
        │     角色 B ↗                  │
        │       可拍区域                │
        └──────────南侧入口─────────────┘

axis: A—B；A 在 B 东北方向，B 面朝东北望向 A；A 面朝西南。
初始: A 站在东北侧；B 坐在西南侧桌边，面向 A。
变化: B 从桌边起身，先转向西北（↖），向【西墙门】移动两步；
    此时尚未必到门口，若出门应另标继续步行/出画的动作。A 留在原位。
可拍区域：南侧开阔，西墙门处可通行，不阻挡 B 的动线。
不在未确定摄影机画面投影前宣称“屏幕向左”或“向后退”。
```

若使用南侧入口，需明确写“南侧入口”，并重画变化动线；不可把“向门走”当作已明确目的地。画面左右须从机位、镜头方向和轴线推导，而不是等同于场景东/西。此图仅用于验证空间关系，实际场面调度与 Shot 数量、机位由导演按锁定剧本自主设计。
