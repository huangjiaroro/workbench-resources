# Verification Evidence · 证据化完成声明

不以模型自述代替执行事实。每个完成声明必须回答：
1. **依据是什么**：变更文件/版本或 commit、需求/验收标准。
2. **用什么验证**：实际命令/测试步骤、运行时环境、执行时间、退出码、相关输出。
3. **验证覆盖哪里**：功能/回归/环境/权限/异常路径，哪些未执行。
4. **结果是什么**：通过、失败、阻塞、未验证，清楚标记各项而非笼统“没问题”。
5. **谁批准什么**：作者自测、QA 测试、Code Review 和负责人验收属于不同事实，不能混同。

如果因工具缺失、账号权限、运行环境或额度问题无法验证，就报告“未验证/阻塞”并解释影响，不推断成功。不重复运行高副作用操作以验证；使用模拟/只读或经用户批准的测试环境。

参考：obra/superpowers `verification-before-completion` 证据优先原则。
