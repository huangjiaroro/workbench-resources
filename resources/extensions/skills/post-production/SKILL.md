# 剪辑与成片

核对本次用途、锁定 Script、`video-production` 产物顶部按 Shot 顺序登记的已生成素材版本或有序组成片段及取用范围，以及实际可用音频、字幕和素材。同时读取 `shot-plan` 产物（含切点和导演剪辑意图）、Shot 内的对白定位及动态时间轴、`bgm-plan` 中必要配乐意图及本轮曲目记录；对白按 Shot 定位后从锁定 Script 取得完整原文。需要追溯技术生成时查看 Production 下部记录，空间与动作争议回查 director-plan、performance-plan、shot-plan 的计划状态和已观察的实际状态。缺失依赖只影响对应部分，明确当前可完成范围，不用占位素材冒充真实结果。**可以先行接手真实已生成、但未经视频制作人逐段视听验收的素材与明确音轨待办**。后期需据导演 Shot、原文对白和实际动态/音轨检查本次采用范围，不以 GENERATED 作为可用内容的保证；收到导演规划局部变更时，核对 Production 记录的该 Shot 版本/哈希，过期画面不能冒充符合新版导演决定。

按叙事关系组织剪辑，维护片段来源、取用范围、声音关系、字幕和必要工程参数。对白清楚、音乐进入与退出有依据，声画表达按作品目标判断。收到声画分离的画面候选时，核对原定对白、发声者、声线、时序和音频来源，**只用已验证且获准的工具**完成补声、对轨和混音；不能执行时如实标记缺口，不能将缺少关键对白的画面导出冒充完整成片。涉及关键因果、人物行为或锁定事实变更时交主创和编剧决定。

接入场景配乐时，根据当前采用画面的实际时序核对曲目的适用范围、进入与退出、长度及对白空间，再实际剪入、对齐和混音。在当前后期记录中保留采用曲目与音频版本、源取用区间、成片使用范围和未完成事项。画面换版、取用区间或剪辑节奏改变后，只核对受影响的音乐与声画关系，不能沿用失效的秒数；需要修订源音乐或导演意图时反馈负责人协调原作者。

**取用范围与混音执行边界**：`video-production` 中记载的源视频取用范围不能替代真实视频裁剪。当前 `wb-media assemble` 只接收整条路径、不接收起止时间；若需部分片段，必须先通过已验证且获准的工具生成真实已裁剪文件并核对哈希，再交 assemble；工具缺失时标记 `BLOCKED`，不擅自把整条源视频作为替代。独立对白/画外音对轨混音也必须核实真实支持的执行工具，不能因素材齐备就宣称已混音。

使用当前授权的编辑和导出能力，记录真实工程及输出。观看和收听实际导出版本，检查时长、画面、对白、字幕、声音平衡与结尾完整性；导出成功不能代替观看验收。源音乐或源视频问题分别交对应制作员工。

按作品约定路径保存剪辑记录或交付文件，生成媒体直接写入作品结果目录，受任务有效授权约束。完成当前成片或局部修改后交接，发布与投放需要单独的明确任务与授权。
