# 剪辑与成片

核对本次用途、锁定 Script、`video-production` 索引中按实际采用顺序登记的 Clip、Shot 对应及取用范围，以及实际可用音频、字幕和素材。同时读取 `shot-plan` 产物（含切点和导演剪辑意图）、按逐 P 规划表的 Shot ID 与衔接组装实际 Shot 内的对白定位及动态时间轴（P 局部时间各自起算，组装后换算至镜内时间；跨镜 P 仅取各行范围）、`bgm-plan` 中必要配乐意图及本轮曲目记录；对白由相应 P4 片段及逐 P 表定位，并与锁定 Script 核对完整原文。需要追溯技术生成时查看所用 Clip 的 prompt.md 与可用来源记录，空间与动作争议回查 director-plan、performance-plan、shot-plan 的计划状态和已观察的实际状态。缺失依赖只影响对应部分，明确当前可完成范围，不用占位素材冒充真实结果。**可以先行接手真实已生成、但未经视频制作人逐段视听验收的素材与明确音轨待办**。后期需据导演 Shot、原文对白和实际动态/音轨检查本次采用范围，不以 GENERATED 作为可用内容的保证；收到导演规划局部变更时，核对 Production 记录的该 Shot 版本/哈希，过期画面不能冒充符合新版导演决定。

按叙事关系组织剪辑，维护片段来源、取用范围、声音关系、字幕和必要工程参数。对白清楚、音乐进入与退出有依据，声画表达按作品目标判断。先核对实际源视频已有声音，保留可用原声；按明确的声音待办处理缺失对白、旁白或替换配音，避免重复叠加。核对原定对白、发声者、声线、时序和音频来源，使用已验证且获准的工具完成补声、对轨和混音；缺少必要能力或声轨时标记缺口。涉及关键因果、人物行为或锁定事实变更时交主创和编剧决定。

接入场景配乐时，根据当前采用画面的实际时序核对曲目的适用范围、进入与退出、长度及对白空间，再实际剪入、对齐和混音。在当前后期记录中保留采用曲目与音频版本、源取用区间、成片使用范围和未完成事项。画面换版、取用区间或剪辑节奏改变后，只核对受影响的音乐与声画关系，不能沿用失效的秒数；需要修订源音乐或导演意图时反馈负责人协调原作者。

**取用范围与混音执行边界**：`video-production` 中记载的源视频取用范围不能替代真实视频裁剪。当前 `wb-media assemble` 只接收整条路径、不接收起止时间；若需部分片段，必须先通过已验证且获准的工具生成真实已裁剪文件并核对哈希，再交 assemble；工具缺失时标记 `BLOCKED`，不擅自把整条源视频作为替代。独立对白/画外音对轨混音也必须核实真实支持的执行工具，不能因素材齐备就宣称已混音。

使用当前授权的编辑和导出能力，记录真实工程及输出。观看和收听实际导出版本，对照本轮采用的 Shot Plan 及逐 P 时序，核对各 Shot 的实际取用区间、镜头次序、时长、表演、原文对白及声画是否完整实现，同时检查字幕、声音平衡和结尾完整性。按实际时间线核对覆盖缺口及非预期重叠；时长差异须有与已采用导演决定一致的剪辑或重叠依据，不以源文件数量、导出成功或总时长接近代替内容检查。缺失或不符合导演方案的源视频、源音乐交主创协调对应作者返修，不通过删减、加速或重排掩盖缺口。未覆盖本轮获准范围或必要声画未齐时，只交付实际完成部分并明确缺口，不判定完整成片通过。

按 assembly 契约保存当前剪辑记录及对应成片、字幕等真实交付文件，媒体与 assembly.md 同一对象目录；需要保留的旧版及候选放入该对象 archive/，内部自由管理。完成当前成片或局部修改后交接，发布与投放需要单独的明确任务与授权。
