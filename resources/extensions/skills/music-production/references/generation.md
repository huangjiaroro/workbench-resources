# 音乐生成指南

## 能力与路线核对

使用前通过 list_plugins 核对本轮可用插件及命名配置，读取相应插件说明与 CLI 帮助。字段、模型、连接和权限以当前准确版本为准，不根据服务品牌猜测能力。

用户指定服务或账号时按指定路线核验；该路线无法完成任务时说明缺口，变更前取得确认。用户未指定时，按当前组织的工具优先级核验已授权路线是否支持本次所需的固定歌词、纯音乐或其他音乐生成模式。首选路线满足要求时直接采用；能力不足或不可用时，再按组织约定核验其他已授权选项。没有指定路线或组织偏好时，从实际可用的音乐能力中选择符合交付要求的路线。

记录选择的提供方、工作流／CLI 版本与账号范围。既定路线失败时，核对其他已授权可用选项并反馈选择，不静默更换服务或账号；涉及新授权或费用时先确认。没有可执行路线时，交付已有歌词／设计与具体阻断，不能声称音频完成。

## 模式与参数编译

保留已确认歌词；根据实际能力与授权选择固定歌词、纯音乐或自动歌词模式。需要保留原词时使用支持固定歌词的路线。

将人声、曲风、情绪、配器、节拍、BPM、调性、结构与目标时长编译到 Prompt；接口明确支持时才使用独立参数字段。无原生精确控制能力时，这些只是制作目标，剪辑依据真实输出。文本 `references` 字段不等于支持上传参考音频，配音用 voice_id 不能直接当成歌声音色输入；不能据此承诺指定歌手音色、精确音符、分轨、乐谱或局部音频编辑。

## 提交、恢复与结果

提交一次，保存真实输入、所选路线、返回信息及任务 ID，不虚构服务端模型。有外部任务 ID 时按该插件说明查询原任务；失败先检查是否已有输出和实际状态，未知提交不自动重提，不套用视频插件的恢复方式。

修改输入后保留必要版本与原始音频，标明当前结果。生成完成后核对音频文件真实存在、可读取且与本次回执对应，再按用途完成试听与交付；生成成功不代表内容已经验收。
