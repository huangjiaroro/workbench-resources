# 从单集正文提炼续作 State

State 只保留后续需要继承的已发生事件、人物所知/所言、关系和承重物件变化、当前推论与未解问题；不是剧情梗概、心理分析或第二份正文。定位通过 episode-state 与 episode 参数。

以本集完整精确正文及有效前情为依据，注明正文版本与必要原文位置。事实、人物认知、未定结果及前后继承按[单集连续性方法](../references/continuity-guidance.md)核对。延续仍适用事实，修正已被新事件改变的认识；不机械复制每集全部人物和空栏目。客观事实、人物陈述、推论与未来计划分清，不把怀疑写成确认。未交代的结果保留为未确定，不自行补出昏迷、关押、转移或物件回收等既成事实；若后续确实需要明确结果，先补足正文并同步 State。人物已说出或听到的重要信息，应与正文原话和实际在场条件一致。

可按本集需要用简洁小节组织：已发生与续作变化、人物所知/所言、承重物件、当前推论、未解问题。人物行为和知识来自正文，不用概括性性格压掉具体反应。**编剧 State 只保留会影响后续叙事的空间位置、动作和物件状态**。导演在 `director-plan` 维护空间与光线基准，在 `performance-plan` 维护表演状态，在 `shot-plan` 维护机位与计划中的镜头衔接。实际生成镜头的衔接、素材状态与技术 Clip 归视频制作人的 Production 记录。不要把未演出的镜头设计写成正文已发生事件。

当集编剧在 C1 依据已确认正文提炼并保存内部 State 工作稿；C2 独立回读该稿及最终正文、Canon 和前集有效状态，核对实际状态来源，修正并复查后集中保存本轮已完成且一致的正文、State 和相关设计，交负责人验收。正文实质返修后，由编剧按[修订影响核验](../references/revision-guidance.md)同步受影响 State，冲突先定位原文。下一集采用有效版本，状态不能覆盖正文。
