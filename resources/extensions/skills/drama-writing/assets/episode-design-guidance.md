# 单集戏剧设计稿

`episode-design` 随创作保存关键设计，与 Script、State 一并交付。导演据此理解人物意图、潜台词与场景目的；剧情事实、动作及对白以有效 Script 为准。按 [SKILL.md](../SKILL.md) 的 W1–W4 依赖完成下列四类内容，真实路径由产物契约解析。

## W1｜人物行动与冲突

读取[人物行动索引](../references/character-action/index.md)及适用方法。对本集实际推动冲突的主要人物分别说明：
- 当下处境、具体目标、动机及重要知情边界；目标之间为何冲突。
- 已采用的行动策略、对手怎样反制、人物如何根据反制改变策略。
- 关键选择和代价，行动造成的关系或处境变化。

不能只介绍人物性格；无需为无承重行为的背景人物逐一分析。

## W2｜单集结构与信息

读取[单集结构索引](../references/episode-structure/index.md)及适用方法。
- 进入本集的未解决处境及与前集的承接。
- 实际事件顺序：行动 → 后果 → 新压力或选择；主要升级、转折及其成立条件。
- 关键事实由谁掌握，观众何时获得何种信息，角色何时发现或误判；悬念、揭示和反转依托的具体事实。
- 结尾实际改变的处境、人物关系或问题；需要延续的悬念及其依据。

不能用“冲突升级”“爆点”“结尾卡点”等标签替代事件因果。

## W3｜场景设计

读取[场景设计索引](../references/scene-craft/index.md)及适用方法。按采用的场景顺序描述，每场至少体现：

| 内容 | 应回答的问题 |
| --- | --- |
| 进入状态与目标 | 此时人物处境如何，实际要改变什么？ |
| 阻碍、行动与反制 | 谁做了什么，对方如何回应，怎样形成下一步选择？ |
| 戏剧变化及离开状态 | 哪个事件造成变化，人物获得或失去什么，如何接到后续？ |
| 承重空间、道具及信息（如涉及） | 怎样实际参与行动、触发反转或者限制选择？ |

简单过渡场可简写，但必须能接上前后事实。

## W4｜对白与潜台词

读取[对白索引](../references/dialogue/index.md)及适用方法；喜剧任务按需选用[喜剧专业索引](../references/comedy/index.md)。

对关键语言交锋写清场次、双方说话意图及对立目标、公开表达与隐藏意图（如有）、具体语言策略、对方回应与变化；说明角色声音、关系差异怎样体现为措辞、沉默、停顿或行为。完整原文对白由 Script 承载。

## 完成判据

- 四类结果都有具体内容并可对应实际场景或人物；允许合并叙述，但相关信息必须可定位。已有有效设计可引用准确位置和版本。
- 关键决定有实际行动、反制、因果、信息变化或语言策略支撑，必要取舍说明理由与成立条件。
- 正文成形或修订后检查设计与实际采用事件、场景和人物意图一致；未决或候选内容与采用决定分开，按真实来源区分用户锁定要求与专业选择。

按需要组织标题、表格或自然语言，无固定篇幅，不另交阅读记录或阶段报告。不给表演预设秒数或镜头。缺少实质设计结果时回对应 W 步骤补足。
