# 单集戏剧设计稿

`episode-design` 随创作保存关键设计，与 Script、State 一并交付。导演据此理解人物意图、潜台词与场景目的；剧情事实、动作及对白以有效 Script 为准。按 [SKILL.md](../SKILL.md) 的 A 阶段独立完成 A1–A4，分别在员工自己的工作空间保存独立工作稿；每一步先回读已保存的前置设计。以下是最终设计稿结构，不是一次性填表任务。A5 整合并保存完整工作稿，独立回读、检查、修正并复查后供正文写作使用；正式写入时机按技能的阶段完成规则执行。真实路径由产物契约解析。

## A1｜人物行动与冲突

读取[人物行动方法](../references/character-action/craft.md)及适用方法。对本集实际推动冲突的主要人物分别说明：
- 当下处境、具体目标、动机及重要知情边界；目标之间为何冲突。
- 已采用的行动策略、对手怎样反制、人物如何根据反制改变策略。
- 关键选择和代价，行动造成的关系或处境变化。

不能只介绍人物性格；无需为无承重行为的背景人物逐一分析。

## A2｜单集结构与信息

读取[单集结构方法](../references/episode-structure/craft.md)及适用方法。
- 进入本集的未解决处境及与前集的承接。
- 实际事件顺序：行动 → 后果 → 新压力或选择；主要升级、转折及其成立条件。
- 关键事实由谁掌握，观众何时获得何种信息，角色何时发现或误判；悬念、揭示和反转依托的具体事实。
- 结尾实际改变的处境、人物关系或问题；需要延续的悬念及其依据。

不能用“冲突升级”“爆点”“结尾卡点”等标签替代事件因果。

## A3｜场景设计

读取[场景设计方法](../references/scene-craft/craft.md)及适用方法。按采用的场景顺序描述，每场至少体现：

| 内容 | 应回答的问题 |
| --- | --- |
| 进入状态与目标 | 此时人物处境如何，实际要改变什么？ |
| 阻碍、行动与反制 | 谁做了什么，对方如何回应，怎样形成下一步选择？ |
| 戏剧变化及离开状态 | 哪个事件造成变化，人物获得或失去什么，如何接到后续？ |
| 承重空间、道具及信息（如涉及） | 怎样实际参与行动、触发反转或者限制选择？ |

简单过渡场可简写，但必须能接上前后事实。

## A4｜对白与潜台词

读取[对白方法](../references/dialogue/craft.md)及适用方法；喜剧任务按需选用[喜剧专业方法](../references/comedy/craft.md)。

对关键语言交锋写清场次、双方说话意图及对立目标、公开表达与隐藏意图（如有）、具体语言策略、对方回应与变化；说明角色声音、关系差异怎样体现为措辞、沉默、停顿或行为。完整原文对白由 Script 承载。

## A5｜完成判据（供自检）

- A1–A4 各章节都有具体内容并可对应实际场景或人物。已有有效设计可引用准确位置和版本。
- 关键决定有实际行动、反制、因果、信息变化或语言策略支撑，必要取舍说明理由与成立条件。
- A5 检查人物、结构、场景及对白设计相互成立，未决或候选内容与采用决定分开，按真实来源区分用户锁定要求与专业选择。正文成形或修订后由 B2/B3 检查设计在实际采用事件、场景和人物意图中的兑现。

保留 A1–A4 章节，章节内部按需要使用表格、列表或自然语言，无固定篇幅。正式设计稿表达人物行动、场景目的、事件顺序、信息揭示及语言意图，保留剧情内的时间事实；创作目标时长、段落时间预算和读本粗估留在编剧工作稿及交主创的结果摘要中。具体镜头及表演时序由导演设计。缺少实质设计结果时回对应 A 步骤补足。完成判据供自检，不复制到正式产物。
