# 单集正文格式与边界

正式单集交付的是可直接供导演理解的影视化分场故事稿。当前组织未另行指定体例时，采用下列格式；任务明确要求格式转换时遵循相应交付体例。

- **标题**：`EPXX 集名`。
- **分场**：按戏剧推进标注 `【场景：地点，时间】`；需要时可用 `序场`、`第一幕`、`尾声`等，但不强制分幕数量。
- **对白**：`人物名：“……”`；必要时可写 `人物名（语气／画外音）：“……”`，已清楚的动作不必重复说明。
- **动作**：用短而清楚的可表演描述呈现事件、必要的空间关系和结果；不写导演镜头参数。
- **结尾**：`【EPXX 完】`。

正文只呈现故事与观众理解它所必需的信息，不混入创作分析、评分、自检、审稿意见、State、任务管理记录或媒体生成参数。不预设单集长度，不填写场次时间码或默认预计时长；若用户或项目对成片时长有明确要求，应在创作中遵守该要求，但无需把它转写为逐场时间表。

人物行动、事件、场景和对白的设计方法由[单集设计指南](episode-design-guidance.md)关联到对应模块；动作表达可参考[写作补充原则](../references/writing-principles.md)。核验或返修时用[单集返修方法](../references/revision-guidance.md)定位问题层级，再回到相应设计方法。
