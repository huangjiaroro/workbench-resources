# 单集正文格式与边界

正式单集交付的是可直接供导演理解的影视化分场故事稿。当前组织未另行指定体例时，采用下列格式；任务明确要求格式转换时遵循相应交付体例。

- **标题**：`EPXX 集名`。
- **分场**：按戏剧推进标注 `【场景：地点，时间】`；需要时可用 `序场`、`第一幕`、`尾声`等，但不强制分幕数量。
- **对白**：`人物名：“……”`；必要时可写 `人物名（语气／画外音）：“……”`，已清楚的动作不必重复说明。
- **动作**：用短而清楚的可表演描述呈现事件、必要的空间关系和结果；不写导演镜头参数。
- **结尾**：`【EPXX 完】`。

正文只呈现故事与观众理解它所必需的信息，不混入创作分析、评分、自检、审稿意见、State、任务管理记录或媒体生成参数。按已确认的时长要求控制故事容量；正文记录剧情中的时间事实、动作与对白，目标秒数、场次播放时间预算及读本估时归编剧创作与核验记录。

人物行动、事件、场景和对白的设计方法由[单集设计指南](episode-design-guidance.md)关联到对应模块；动作表达可参考[写作补充原则](../references/writing-principles.md)。B1 在员工工作空间保存完整正文初稿后，B2 独立回读并使用[单集返修方法](../references/revision-guidance.md)定位具体问题，将诊断保存于临时工作稿；B3 据其修订并回读复查，无实质问题直接确认原稿；C2 核验对应 State 后集中写入正式成果。诊断、修订记录不进入正式正文。
