# 喜剧与笑点｜专业资料导航

## 适用、原理与操作路径

- **适用情境**：喜剧前提乏力、人物错位不足、场景不好笑或笑点重复时。
- **专业原理**：喜剧有效性来自人物动机、情境反差、铺垫与意外后果，不来自页数配额。
- **具体操作步骤**：先确定人物当前欲望与尴尬困境→安排目标受阻与升级→比较不同反应/笑点→核查喜剧是否推动人物和情节。
- **注意与边界**：不按每页笑点数、固定 Beat、二稿日程或制片流程自动否决作品。
