# 游戏与竞赛模式研究

用于选择或改造参考模式。先明确想产生的体验、参与者关系、制作限制，以及本次要比较模式还是核验某条规则。

查读真实规则和必要过程，关注参与条件、各方目标与所知、可选行动、收益代价、结束条件。分析规则如何产生选择、信息差和局势变化，区分规则本身与参考作品的特定情节。关键事实或策略成立条件结合事实与机制方法核查。

交接可借鉴的机制、适用条件、改造方向及主要漏洞。模式之间有何不同、为何适合本剧已经清楚时结束；不因调研模式就补齐全套关卡、数值、解法和结局。

需要为正式剧情形成完整游戏设计时，由故事作者负责规则、过程、反制、结算与剧情因果的衔接；研究员按工单提供机制候选、关键事实、成立条件与反例。是否安排独立复核，由负责人根据任务需要决定。
