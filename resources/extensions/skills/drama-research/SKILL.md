# 创作研究

结合当前工单、已有材料与结论用途，自主判断研究问题、范围和深度，参考 [共同研究方法](references/researcher.md)。按实际未知选择资料；不为做全套研究而扩张任务。

| 当前研究问题 | 方法 |
|---|---|
| 市场表现与选题机会 | [受众与市场](references/audience-market.md) |
| 参考作品的故事机制、人物关系、名场面何以成立 | [创意与故事的研究](references/creative-story.md) |
| 游戏、竞赛、关卡机制 | [游戏模式](references/game-models.md) |
| 专业事实、案件或策略因果 | [事实与机制](references/factual-mechanisms.md) |
| 表演、画面、剪辑、声音 | [视听表达](references/audiovisual-expression.md) |
| 配器、曲目与音乐风格 | [音乐](references/music.md) |

需要从研究依据发展原创故事候选时，配合另行安装的 `story-ideation`。研究成果支持取舍；正式设计与故事文件按当前组织分工由对应作者维护。
