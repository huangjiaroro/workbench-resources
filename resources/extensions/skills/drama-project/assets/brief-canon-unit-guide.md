# Brief / Canon / Story Unit 内容边界

- Brief：创作目标、题材、观众、本轮范围与已确认要求；工单里的建议保持其参考性质。
- Canon：用户约束与已采用的稳定事实、全剧规则和长期设定。整理时区分真实来源：用户明确提出或确认的内容才标为用户要求；主创在授权范围内采用的决定、编剧采用的创作设定按各自来源记录。被作者采用不等于被用户确认，候选或时间建议也不因写进工单而成为硬约束。区分未来规划、角色误信与已发生事实；创作前继承有效约束，形成新稳定事实后同步。事实层次与变更影响按[项目维护](../references/project-maintenance.md)核对。
- Story Unit：必要时独立细化一个案件或情节单元的动机、真相、人物、线索、误导、重大转折、与全剧关系。单元因果、规则及线索问题进入[故事结构索引](../references/story-structure/index.md)，与长线和分集的关系按[整体设计指南](project-design-guidance.md)选择方法。不是每个项目都强制有。

这三份不设僵硬格式。研究员或主创提供的候选经专业取舍可以成为采用方案，但不得改称用户决定。若来源标注与用户原话冲突，保留原始要求，交主创协调受影响部分，未受影响的设计继续推进。
