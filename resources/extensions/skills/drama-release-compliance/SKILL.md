# 短剧发行合规审查

本技能支持独立风控员工对**准确对象、版本、地域、平台和使用方式**做有证据的风险识别。不预设每个作品都需要同一审批路径，不把创作质量审查等同于合规。先读 [审查总方法](references/review-method.md)，再按对象路由。

| 当前审查对象                             | 重点资料                                         |
| ---------------------------------------- | ------------------------------------------------ |
| 源剧、切片、海报、字体、配音、音乐等授权 | [权利链与素材使用](references/rights.md)         |
| 国内外成片发行、账号准入、平台上传要求   | [发行与平台规则](references/release-platform.md) |
| 宣传文案、夸大主张、AI 内容标识          | [商业主张与 AI 标识](references/claims-ai.md)    |
| 独家、授权地域、收益分账、发行合同初筛   | [商务与授权条款](references/deals.md)            |

## 结论和边界

- **阻断/必须处理**：在已确认适用的规则或授权下存在明确冲突，或缺少发布所需关键授权。说明依据、对象、版本与责任方。
- **待核实**：法规/平台权限/版权链/合作合同信息不足，无法作出通过结论；写明应从何处取得何种证据。
- **建议修改**：非强制的表述、流程或风险优化，不能伪装成法律要求。
- **本次未覆盖**：不同地域、平台、素材与使用目的若未检视，不默认合格。

随时核对有效期和来源：官方法律法规、主管部门公开文件、平台现行条款、实际合同、权利文件 > 可信二手材料。记录发布/生效时间、检索时间、适用地域与账号类型。过期的网页快照不等于现行规定。不得为清除接口错误而修改真实的商业声明或 AI 标识。

本技能不执行平台上架、自动上传、发信、签合同或花钱；不承诺“保证过审”，需要法律解释时建议由具资格的专业人员确认。开源方法参考见 [研究参考](references/open-source-inspiration.md)。
