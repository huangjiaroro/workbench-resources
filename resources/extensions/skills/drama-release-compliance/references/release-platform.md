# 发行与平台审核：正片、宣发和版权合作分开核查

## 工作分类

1. **普通短视频或预告发布**：实际上传账号、API/客户端权限、内容审核、AI 标识和商业宣传规则。
2. **短剧正片连载**：分集、合集、题材、账号资质、备案/审核、节目编号或特定入口（如适用）的规则。
3. **版权发行合作**：平台或发行商的投稿资格、真实发行方、合同签署、地域/期限/独家约束与材料要求。
4. **广告推广**：自然发布以外的商业化投放规则、广告主资质、声明、费用授权。

国内抖音/快手/B站/红果等场景，海外 YouTube/TikTok/Instagram/专业短剧 App 均需要按**当前实际平台、地区、账号类型**核对。不要因为同集团平台就认为注册资格、审核和发布接口通用。

## 动态法规和官方规则

- 遇到中国大陆短剧发行，核对主管部门现行微短剧管理文件、广电平台分类管理与平台审核要求，并记录该作品实际类别和需要的程序。无法归类则给出“待平台/主管部门核实”与材料清单。
- 海外发布核对目的国/平台适用规定、音乐和授权地域、年龄分级、广告声明及 AI 标记要求。
- 面向海外的境内制作作品，单独核对中国境内制作与对外发行的适用要求，不能假定“只发海外就不涉及国内要求”。
- 上传 API 是否可用由插件和官方开发文档核实；GitHub 自动化工具不是发行资格凭证，任何风控绕过不是审查通过。

## 交付

形成逐平台矩阵：`拟发布作品版本—使用性质—需具备资质/文件—当前证据—缺口—阻断/待核实—可继续的人工步骤—链接与核对日`。缺少官方证据不能写“无需备案”或“已符合全部规定”。
