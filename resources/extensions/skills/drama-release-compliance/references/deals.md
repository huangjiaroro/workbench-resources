# 版权合作与发行条款：风险初筛

发行商务经理负责推进合作，商业变现经理负责收益测算；本资料供独立风控识别合同疑点，不能替代律师审定。

## 需要逐项确认的条款

| 维度       | 重点核查                                                         |
| ---------- | ---------------------------------------------------------------- |
| 权利类型   | 播放、发行、改编、剪辑、翻译、配音、广告推广、再授权是否分别约定 |
| 区域及语言 | 中国大陆/海外各地域、具体语言版本是否被覆盖                      |
| 排他性     | 独家/非独家、是否限制自有账号预告和片段                          |
| 时间       | 开始/届满、自动续约、下架、终止与素材回收                        |
| 收入       | 保底、买断、分账口径、可扣除成本、结算周期、币种和税费           |
| 风险       | 侵权责任、赔偿、违约、素材归属、数据访问和退款/撤稿条件          |
| 对外签署   | 签字主体、授权代表、保密义务、合同存档和用户最终批准             |

## 输出

列出 `具体条款位置—现有理解—风险—需澄清的问题—建议负责方`，重要事项由负责人向用户呈报，需要的法律解释由合格专业人士确认。不得未经授权自行接受报价、签署协议或提供含敏感信息的材料。
