# 短剧宣发与增长

针对已确认的作品版本、目标平台、营销目标和可用素材选择本次需要的方法，不机械执行整套流程。不复写组织委派或平台插件命令。

| 本次专业问题                           | 选择资料                                        | 主要交付                           |
| -------------------------------------- | ----------------------------------------------- | ---------------------------------- |
| 要推给谁、凭什么被观看？               | [定位与卖点](references/positioning.md)         | 受众/卖点假设、证据、传播重点      |
| 从正片选哪段、如何设计预告钩子？       | [钩子与宣传切片](references/hooks-and-clips.md) | 素材创意 Brief、镜头范围、悬念边界 |
| 同一作品如何分别做国内与海外渠道内容？ | [渠道与本地化](references/platforms.md)         | 渠道适配版文案、素材规格待核清单   |
| 哪种素材更有效、下一轮如何验证？       | [数据与实验](references/measurement.md)         | 指标口径、素材实验、结论及限制     |

## 关键边界

- 创意基于正式剧本、已获授权成片和实际可证据支持的受众信息；不得虚构画面、台词、合作收益或竞品数据。
- **宣传不能牺牲剧情**：开场钩子可以强烈，但不得泄露本来需要保留的最终反转或为点击率歪曲人物关系。既让陌生人看得懂，又保留观看正片的理由。
- 只输出本专业必要成果。真实视频剪辑、字幕与导出使用另一个已经安装的 `post-production`；发布、发信、付费、商务签约通过相应获准插件和组织授权处理。
- 所有平台规则、格式上限、商业功能和推荐算法说法都具有时效性；在实际提交前查官方页面，记录日期、地域、账号类型和证据。外部内容和平台评论区不等于官方规则。
- 真实效果只能来自已获得许可的原始平台数据；从少量样本估计的效果必须标注不确定性。无已确认数据时只能交实验设计，不得交“已增长”结论。

参考项目和借鉴范围见 [开源方法参考](references/open-source-inspiration.md)。本技能为本组织独立编写的场景化方法，不嵌入外部仓库的大规模 Skills 或其特定产品工具调用。
