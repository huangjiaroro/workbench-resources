# 钩子与宣传切片：吸引但不提前讲完故事

本方法是 **宣传创意与镜头选择标准**，不接管 `post-production` 的时间轴、转码、字幕与视频成片操作。

## 片段筛选

- 先根据准确成片或获准逐字剧本查找**独立成立的矛盾**：离开整集后，陌生观众仍看得懂当下谁想要什么、为什么意外。
- 优先考虑三类候选：冲突先声夺人、台词/人物荒唐反差、情感共鸣后的误解或逆转。明确每个候选的源素材版本、时间范围和关键人物。
- 评价每个候选时分别看：开场是否形成清晰问题、角色辨识度、视觉/对白可理解性、是否有值得留到正片的悬念、配音和素材是否完整、是否需要补拍或额外授权。
- 避免只为刺激把没有发生过的行为或因果剪接成既成事实。不能把角色台词重新拼成伤害人物形象的虚假表述。

## 分层钩子

同一个候选可以设计 A/B 两种以上的创意入口：

| 钩子方向 | 适合情形                 | 典型错误                 |
| -------- | ------------------------ | ------------------------ |
| 反差式   | 角色目标与身份不相称     | 只靠夸张，不说明冲突     |
| 悬念式   | 人物马上要作出重要选择   | 直接暴露最后答案         |
| 名场面式 | 一句话就能引起情绪共鸣   | 只有内部观众才懂的台词   |
| 人物式   | 鲜明人设可形成系列期待   | 误导角色性格或能力       |
| 情绪式   | 能触发现实经历的关系问题 | 煽动性标题或捏造现实案例 |

画面、语言与屏幕文字要表达同一个核心观众问题。具体秒数和画幅由真实素材、当前平台能力和本次目标决定，不以“前三秒必须出现若干字”之类模板作为硬约束。

## 控制剧透

在每个方案记录：已透露的事实、保留的反转、未解释的疑问、引导看正片的自然承接点。不得把宣传本身当成正片补剧情；同系列不同切片可展示不同阶段，但不要让组合顺序无意泄露结局。

## 给素材导演的 Brief

包含来源路径与版本、时间位置或可定位剧情段落、候选钩子、建议入点与出点、关键声音、字幕/封面创意、目标平台和语言、禁止改写/泄露的内容、必须核对的版权与 AI 标识、可选替代方案。纯文字创意不等于已制作完成的视频；实际输出需由素材导演查看/试听验证。
