# 渠道与本地化：同一作品，不等于同一份上传文案

先根据**本次获准且实际可用的渠道**设计作品适配。把平台分为三类：

| 业务通道            | 内容对象                                  | 核心判断                                               |
| ------------------- | ----------------------------------------- | ------------------------------------------------------ |
| 正片连载 / 完整剧集 | 集数、顺序、封面、字幕和归档              | 版权与可发布资格、集数管理、是否已有独家约束           |
| 公域宣发            | 高光切片、预告片、片场/制作幕后、角色介绍 | 目标观众是否在这里、钩子是否独立成立、引流动作是否允许 |
| 专业短剧版权发行    | 版权链、项目资料、作品样片、分集列表      | 发行方资质与合作入口、地域/期限/独家、材料准确性       |

## 国内渠道

抖音、快手、B站、视频号、小红书等可以承担不同的内容传播角色；红果/短剧创作者中心等属于专业发行合作通道，不能仅凭“平台有上传按钮”推定自动版权发行 API 可用。对需审核/备案/平台资格的情形交独立风控判断。

## 海外渠道

YouTube（长短视频）、TikTok、Instagram Reels、Facebook Reels 和专业短剧 App 的发行合作路径不同。先确认发行地域、语言、肖像/音乐/字体/配音等素材的跨地区授权。字幕翻译保留人物关系、梗和情绪动机，而不是逐词直译；不擅自改剧情或文化事实。不得假设某个平台公开 API 支持自己工作台的个人自动发布。

## 提交前校验

- 检查当次平台官方规则：文件格式、时长、尺寸、标题字段、上传资格、人工审核、账号/商业权限与 AI 标识。
- 每个平台版本记录准确源文件、内容语言、标题/封面、导流目的、隐私和定时安排；平台能力不支持则采用合法的人工交接流程。
- 插件的 CLI 命令、OAuth 和授权按它自己的配套使用技能执行，不把本业务方法写成插件说明；不使用绕过验证码、模拟隐蔽操作等手段。
- 对已经发生的发布要保存实际平台回执和链接，不以素材准备完成或上传尝试代替已上线事实。
