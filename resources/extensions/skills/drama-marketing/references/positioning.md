# 定位与卖点：把作品事实转换成传播承诺

本方法用于作品宣发、预热、重启推广和渠道改版。先判断本轮目标是**发现新观众**、**推动实际观看**、**促进合法转化**还是**为商务发行准备市场证据**，目标不同不要用同一指标评价。

## 必要依据

- 作品准确版本、官方名称、类型、目标受众、可公开角色设定、可用视频和台词、未获授权素材清单。
- 用户已确认的预算、渠道、语言和上线节奏；未知视作未知，不自设花钱预算。
- 研究报告按事实/观察/推断/假设区分：例如“某个视频高播放”不证明某个钩子具普遍效果。

## 专业判断

1. 用一句话表达观众会得到的主要情绪或体验，而不是制作技术堆砌，如“会笑，也会想起自己不敢拒绝的时刻”。
2. 提出 2—4 个差异化传播角度，并逐项指向具体剧本情节、镜头、人物关系、台词或可引用的官方资料。
3. 区分作品品牌和素材选题：同一部剧可以有角色搞笑、现实共鸣、荒唐委托、剧情悬念等素材线，但要共同指向同一作品。
4. 受众人群先用可观察的观看动机和平台环境描述，避免未经证实的绝对画像和刻板标签；优先用低成本试发验证。
5. 把“剧情精彩”转为可操作的宣传 Brief：情绪入口、特定观众问题、画面依据、节奏、不可剧透范围、希望引导的合法行动。
6. 对竞品案例记录出处、采样日期、样本偏差和可借鉴的结构，不照搬视频/音乐/台词与商标。

## 输出与验收

输出 `目标—受众动机—真实卖点—证据—素材方向—渠道假设—风险与待证项`。每条主张可以追溯至真实作品或来源；不写“保证爆款”。制作和运营的具体责任仍归各自岗位。
