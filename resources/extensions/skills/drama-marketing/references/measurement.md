# 宣发效果测量与小规模实验

目标是根据可复核的数据作**下一轮专业判断**，而不是仅输出漂亮的图表。优先控制低预算、低风险试验。

## 数据口径

| 问题                 | 指标或证据                       | 核对点                                         |
| -------------------- | -------------------------------- | ---------------------------------------------- |
| 有人看到吗？         | 曝光量、覆盖人数                 | 曝光与独立用户数不同；平台字段定义不同         |
| 愿意点开吗？         | 点击/打开、CTR（如适用）         | 分母是曝光还是推荐展示？不要混用               |
| 愿意继续看吗？       | 平均观看时长、完播、特定节点留存 | 视频时长、平台计数和自动播放机制不同           |
| 愿意互动或传播吗？   | 评论、收藏、分享、关注           | 自然/付费与异常流量需区分                      |
| 能带来观看或收入吗？ | 正片转化、授权转化、实际到账     | 必须有事件关联或真实账单；没有关联不得声称归因 |

## 比较方法

1. 先固定比较目标和素材版本、平台、账号、语言、目标人群、统计时窗，列出不同因素。
2. 若要比较“钩子是否更好”，尽量只变更钩子或文案中的一个主变量；素材/预算/时间全部变了时不声称单因果。
3. 小样本直接写样本量和观测结果，不做无依据的显著性或 ROI 保证。
4. 对跨渠道数据先统一指标定义、金额币种与时间区间；缺少可比较数据时做分渠道结论，不粗暴合并。
5. 从失效模式回溯：触达不足、开头流失、正片链接缺失、观众误解、平台审核限制等，不把所有低播放归因于创意差。

## 交付

至少包含 `素材/渠道与版本—真实来源—日期—指标定义—观测—可能解释—不能排除的原因—下一轮建议`。没有原始报表时提供采集字段清单；任何预算动作必须另行授权。
