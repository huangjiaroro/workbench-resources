# 视频关键帧与生成连续性

## 三件事必须区分

1. **E：生成后抽帧**：每个 Clip 成功后，只依据真实媒体用插件抽取必要关键帧，记录源文件、实际源时间、图片路径、哈希及必要用途。更新 Production 索引后才进入下一 Clip。不要求立即打开关键帧、看图、看完整视频或听音。抽帧是供后续按需使用，不是质量验收。
2. **B：生成前按实际状态依赖看图**：先以 director-plan、performance-plan 与 shot-plan 理解当前计划位置、朝向、动作及状态；只有需要掌握或确认实际媒体状态时，才先读取 Production 中对应前序 Clip 的帧索引，定位实际图片并阅读。复用来源明确、仍适用的已确认状态，不机械重复查看。交接武器、倒地、位置转换、血迹具体形态或衣物破损等结果需要实际依据时必须确认；普通切机位、反应特写不自动触发读图。**相关来源可跨 Clip、Shot 和场次，不必是紧邻前段。**查看后仅记录实际观察事实；无法可靠判断则说明未知，必要时定向补查或反馈主创，不推断整段合格。导演预期不冒充实际确认，实际生成错误也不覆盖导演决定。
3. **视频参考输入**：读取关键帧取得状态与把图片提交给模型是不同决定；参考输入由本技能 [参考输入政策](../prompt/reference-policy.md) 维护。观察记录提供本次真实依据，不自动成为模型绑定。

## 提交前的有限确认

有实际状态依赖时，等待对应前段输出并完成必要观察；只确认本次承接所需内容，不扩大为逐段完整视听质检。局部静帧不能证明动态、口型或视频音轨合格。

## 状态版本

`video-production` 索引按 Scene 和 Shot 记录实际视频、抽帧索引、状态与版本。在已有记录中简要保留已观察的相关状态及源帧/时间，后续仍适用时直接复用，不另建状态文件；未查看或已过期的状态不写成已确认。关键帧路径与源视频对应；源视频重生后更新相关帧与观察记录，不用旧版本冒充新结果。无法确定状态就写未确认，不凭空推断。需要改变导演设定的走位或机位时，反馈主创协调导演；涉及剧情、关键动作或对白内容时，交主创协调编剧修订并重新采用，不回填导演文件或正文。

上游 Clip 更换或重生后，按已有参考绑定和状态观察记录定位真正依赖旧视频、旧帧或旧状态的后续范围，在原 Production 中注明受影响条目及待核对原因，并通知已接手的后期或其他使用者。先判断相关位置、持物、朝向或外观是否实际改变：仍成立的后段继续复用，失配部分按影响处理；不因源文件换版自动重生全部后段。尚未核对时保留真实已生成文件，但不能把它们当作已适配新版状态的依据。

媒体操作见 [media-operations.md](media-operations.md)，Production 记录见 [shot-execution.md](shot-execution.md)。
