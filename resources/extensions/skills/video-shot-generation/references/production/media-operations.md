# 视频输出、真实抽帧与文件回执

先核对可用插件与命令实际说明，不能因为技能里写了某个命令就假定本次工具可用。

## 保存真实生成结果

- 使用 H3/ComfyUI/真实插件生成后，读取任务回执并确认输出视频**真实存在**；记录实际路径、字节/哈希、时长与可得的技术参数。提交结果未知时依据任务 ID 恢复查询，不猜测成功，也不重复提交未知任务。
- 每个成功 Clip 在 E 使用已安装的 `media` 插件或等效工具抽取**必要关键帧**。依据实际时长、导演时序及预计承接需求选择起止附近和关键动作/状态转换时间点，不固定抽帧数量，不把计划时间误称为已观察状态。例如媒体插件 `wb-media inspect` 支持 `path`、按需 `frameTimes`，以实际工具说明与回执为准。
- 保存实际抽帧图片路径、源视频、真实帧时间、版本与哈希并更新 Production，供下轮 B 按需定位。**生成后只抽取、登记，不强制读取图片、连续观看视频或收听音轨**，也不以抽帧代替视听验收。

## 下一个技术生成任务

状态承接与必要观察按[连续性方法](continuity.md)判断；需要裁图等派生文件时，核对工具回执、真实文件及其来源，模型输入选择按本技能的 [参考输入政策](../prompt/reference-policy.md) 编译。

## 交接职责

当前素材与关键帧的真实路径、取用范围、来源及必要状态留在 `video-production` 正式索引，生成尝试内部自由管理。**整集视频裁剪、拼接、混音、字幕、导出和成片视听验收属于后期及主创**；制作人不执行 `wb-media assemble` 的整集组装。需部分源片取用时，只登记真实片段与取用要求，不将未裁剪的源文件误认为已裁好。
