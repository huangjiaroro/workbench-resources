# 技术视频任务选择与执行原则

## 叙事与技术边界

技术 Clip 依据已采用的 Scene → Shot 顺序，结合连续表演、场景与素材兼容性、模型实际能力和自然时间划分。一个 Clip 可含多个相邻 Shot，一个 Shot 可拆多个技术任务。通常优先同场景；跨场只有既定转场且模型实际支持时才组合。

根据 director-plan 的空间基准、performance-plan 的表演状态、shot-plan 的镜头和内部动态时序选择生成范围。对白按 P4 和 Shot Plan 的原文与说话者定位，确有缺漏或矛盾才回查相关 Script 原文；技术发声与后期声音安排承接已审定时序和实际工具能力。BGM 由独立音乐与后期岗位处理，不为生成依赖。A 只规划整集边界，实际输入与 Prompt 在各 Clip 的 B/C 阶段决定。

## 确定 Clip 覆盖范围

1. 按 Shot Plan 播放顺序，找到可完整实现的连续表演及相邻镜头，按逐 P 规划表的 Shot ID 聚合相邻连续行，取各行自然时长、P 局部时轴及声画要求；在技术编译时换算至 Shot／Clip 局部时间，同镜跨 P 保持摄影连续，跨镜 P 仅取各行覆盖的动作和台词，显式重叠只计一次。不默认逐 Shot 提交。
2. 核对工单制作约束与当前工具、工作流和模式实际支持的单次时长、多镜及参考输入能力。按组织和工单的制作长度要求与实际工具限制取更严约束，兼顾完整发言或动作的自然连续。
3. 按导演顺序组合相邻 Shot，兼顾自然表演、较少技术拆分和模型支持。优先在既定 Shot 边界拆分，不跳过镜头或重复对白。实际模式不支持多镜、输入不兼容或转场效果时缩小范围并说明原因。
4. 一个连续 Shot 本身超过硬上限时，在语义、语法、动作或表演的自然承接处划分技术范围，按状态与参考规则安排续接；不把技术分段变成新的成片切点。须完整覆盖原时长、台词、动作与次序，不通过删字、加速、压缩停顿或缩短镜头硬塞入长度限制；无法忠实实现时交主创协调。
5. Prompt 内沿用 Shot 顺序、切点及内部动态时间轴。对每个覆盖源区间 [a,b]，以 Clip 中该段起点 c 换算事件时间 t 为 c+(t-a)；分割时保留相交区间与动作/声音承接，不重复或跳过。按[制作索引规范](shot-execution.md)记录 Scene、Shot、源内与 Clip 时间范围、分组原因。实际素材是否可用仍需核对，分组完成不等于生成或内容验收。

## 真实结果与依赖

生成输出与抽帧操作按 [media-operations.md](media-operations.md)，必要观察及状态复用按 [continuity.md](continuity.md)。参考输入选择由本技能的 [参考输入政策](../prompt/reference-policy.md) 维护。

逐 Clip 执行与阶段依赖以主技能为准。当前 E 完成后下一轮 B 再依据真实状态按需定位和读取前序帧；无实际依赖时无需读图。即使读取过关键帧，也不能从静帧推断整段动作、口型和声音已经正确。

## 记录和交接

正式 `video-production` 索引记录当前 Clip 顺序与全 Shot 的覆盖、进度、取用范围及素材/抽帧引用。完整实际 Prompt 和必要参考输入、参数随对应视频保存。技术 Clip 与 Shot 允许多对多。缺音轨、后期裁切与混音待办明确标注。生成成功只记 `GENERATED`，不可声称内容已验收；完整成片声画由后期和主创负责。**制作人不得修改导演文件。** 字段详见 [shot-execution.md](shot-execution.md)。

生成声音按当前组织和工单的音频范围编译。
