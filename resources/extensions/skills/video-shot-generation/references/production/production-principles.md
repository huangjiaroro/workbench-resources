# 技术视频任务选择与执行原则

## 叙事与技术边界

视频制作人只执行已审定导演 Scene → Shot，不重新设计 Coverage。一个 Clip 可含多个相邻 Shot，一个 Shot 可拆多个技术任务。分组依据是连续表演、场景/素材兼容、模型实际能力和自然时间，不再使用独立戏剧节拍边界。通常优先同场景；跨场只有既定转场且模型实际支持时才组合。

根据 director-plan 的空间基准、performance-plan 的表演状态、shot-plan 的镜头和内部动态时序选择生成范围。**本技能同一条流程内完成 Prompt 编译与参考绑定**，插件模式以真实说明与回执为准。按 Shot 定位从锁定 Script 提取完整对白及说话者；技术发声与后期声音安排承接已审定时序和实际工具能力。BGM 由独立音乐与后期岗位处理，不为生成依赖。

## 确定 Clip 覆盖范围

1. 按 Shot Plan 播放顺序，找到可完整实现的连续表演及相邻镜头，按逐 P 规划表的 Shot ID 聚合相邻连续行，取各行自然时长、P 局部时轴及声画要求；在技术编译时换算至 Shot／Clip 局部时间，同镜跨 P 保持摄影连续，跨镜 P 仅取各行覆盖的动作和台词，显式重叠只计一次。不默认逐 Shot 提交。
2. 核对工单制作约束与当前工具、工作流和模式实际支持的单次时长、多镜及参考输入能力。本组织使用 ComfyUI 时，单次请求通常以 **12 秒以内为目标，15 秒为硬上限**；完整发言或动作的自然连续有需要且模式支持时，可以使用 12–15 秒。具体工单或实际工具上限更低时取更严约束。这是制作调度的组织约束，不表示所有工作流都支持该时长。
3. 按导演顺序组合相邻 Shot，兼顾自然表演、较少技术拆分和模型支持。优先在既定 Shot 边界拆分，不跳过镜头或重复对白。实际模式不支持多镜、输入不兼容或转场效果时缩小范围并说明原因。
4. 一个连续 Shot 本身超过硬上限时，在语义、语法、动作或表演的自然承接处划分技术范围，按状态与参考规则安排续接；不把技术分段变成新的成片切点。须完整覆盖原时长、台词、动作与次序，不通过删字、加速、压缩停顿或缩短镜头硬塞入长度限制；无法忠实实现时交主创协调。
5. Prompt 内沿用 Shot 顺序、切点及内部动态时间轴。对每个覆盖源区间 [a,b]，以 Clip 中该段起点 c 换算事件时间 t 为 c+(t-a)；分割时保留相交区间与动作/声音承接，不重复或跳过。按[制作索引规范](shot-execution.md)记录 Scene、Shot、源内与 Clip 时间范围、分组原因。实际素材是否可用仍需核对，分组完成不等于生成或内容验收。

## 真实结果与依赖

生成输出与抽帧操作按 [media-operations.md](media-operations.md)，必要观察及状态复用按 [continuity.md](continuity.md)。参考输入选择由本技能的 [参考输入政策](../prompt/reference-policy.md) 维护。

依赖前段实际结果的任务先等待真实输出，再完成本次承接所需的有限状态确认；无实际依赖的任务允许并行。即使读取过关键帧，也不能从静帧推断整段动作、口型和声音已经正确。

## 记录和交接

正式 `video-production` 产物上部列全 Shot 的 Scene/进度/Clip/素材/抽帧，后部存真实 Prompt、参考输入、参数和回执。技术 Clip 与 Shot 允许多对多。缺音轨、后期裁切与混音待办明确标注。生成成功只记 `GENERATED`，不可声称内容已验收；完整成片声画由后期和主创负责。**制作人不得修改导演文件。** 字段详见 [shot-execution.md](shot-execution.md)。

生成阶段不请求独立非剧情 BGM。
