# 生成参考图的实际用途

正式角色、正式场景和正式道具资产可按本次 H3 模式与导演 Shot 需要正常绑定；场景俯视图用于**理解空间调度**，不默认作为写实生成参考图。

在 B3 根据 B1/B2 的计划及实际状态选择当前生成模式和实际模型输入；是否需要补充观察、观察如何复用及何时失效，由本技能的 [关键帧与连续性](../production/continuity.md) 维护。本文件只决定哪些素材作为模型输入。

## 选择生成模式

| 实际任务 | 模式取舍 |
| --- | --- |
| 首次建立场景、常规切镜、反应/正反打及新机位构图 | 优先考虑多参考；选与本镜可见空间和状态相容的真实人物、场景、道具及必要局部参考 |
| 同一连续 Shot 的技术续接、明确必须从已确定画面或姿态起幅 | 优先考虑首帧；实际来源可以是已生成视频的可用尾帧或符合当前构图的辅助图 |
| 已有明确且相容的起幅与落幅，需精确控制连续动作或补充过渡 | 考虑首尾帧；两图需符合导演空间、机位及动作可达性，不把艺术硬切强行变成连续变形 |
| 血迹、伤损等实际局部细节继承，但摄影构图发生变化 | 多参考结合相关局部图，避免旧整帧锁死现拍机位 |

当前 ComfyUI 的 h3-flex-fl 支持必需首帧、可选尾帧，不能同时使用多参考图/音视频，实际输入按插件核实；不为使用首尾帧而强制每一 Clip 额外生成两张图。选择参考时核对本镜空间和可见性，场景设定板若含与当前姿态、位置或构图冲突的强视觉元素，考虑裁取适用区域、选其他现有依据或按需生成辅助图。不要给所有 Clip 机械绑定同一组参考。

**历史完整关键帧不作为下一任务的默认参考图**，按本次镜头关系选择：

- **同一连续 Shot 的技术续接**：需要继承前段构图、人物姿态或动作起始状态时，可选取前段相关整帧/尾帧，按真实支持的首帧、首尾帧或参考模式绑定。记录来源视频版本、帧时间、续接用途及实际输入；首尾帧模式须有真实可用的相应素材，不能假设工具支持或仅靠参考图承诺无缝衔接，不增加导演未设计的硬切。
- **换机位或进入其他 Shot**：不自动套用旧整帧，避免把冲突的旧姿态、构图或额外人物带入新镜；身份与场景优先正式资产，必要的位置/朝向信息可写入 Prompt。
- **局部形态继承**：血迹分布、衣物破口或道具损伤等需要精确承接时，可裁取相关局部，排除与本镜冲突的无关内容，说明用途并核对真实输入支持。

读取关键帧获取状态，不等于必须把图片提交给模型；只有本次生成确实需要时才绑定。不为普通切镜自动制造辅助首尾帧。

同一生成任务的参考输入须核实图片来源、用途与真实绑定；不支持的标签与模式不得假设可用。技术生成范围由制作人按本技能的 [生产原则](../production/production-principles.md) 确定。

确需新出辅助参考图时，遵循当前组织与工单的出图能力选择顺序；采用原生优先规则时，先用本员工原生能力，受限后才使用获准插件。真实生成的辅助图记录在 Production，稳定设计缺口仍按组织分工交视觉设计师，不将辅助图冒充正式资产。
