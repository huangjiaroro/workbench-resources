# H3 全参考模式指南（Ref2VA，自包含适配）

本文与 [h3-base-modes.md](h3-base-modes.md) 和 [prompts.md](prompts.md) 共同构成 `video-shot-generation` 内部可离线读取的完整 Prompt 编写入口。官方原始参考：`MiniMax-AI/MiniMax-H3` 的 `skills/h3-prompt-writing/references/ref-en.txt`。实际插件未支持全参考模式时不得假设其可执行。

## 完整六段结构（不得省略字段或擅自换序）

```text
subject_definitions: ...
summary: ...
retention_analysis: ...
detailed_description: [Shot 1] ... [Shot 2] At 00:04.000, ...
overall_soundscape: ...
non_diegetic_music: N/A
```

1. **subject_definitions**：列出真实提供的 `<Subject N>` 主体、`<Picture N>` 参考图片、`<Video N>` 参考视频、`<Audio N>` 参考音频及各自提供的身份、场景、机位、运动或声音作用。素材选择按[参考输入约定](reference-policy.md)，此处核对模型标签与素材用途的对应关系。多个标签保持全篇一致，声源身份与 `(S1)` 等号码一一对应。
2. **summary**：说明目标视频相对所用参考素材的实际关系，如参考生成、视频编辑、视频续接、音频直接复用或音频风格参考。直接沿用音频信号才标记 `audio reuse`；只借鉴音色、口音、音乐风格或对白信息标记 `audio reference`。不能因请求携带视频/音频就自动断言编辑或直接复用。概括画面剧情及参考角色，不创造未定义标签。
3. **retention_analysis**：逐项说明哪些参考特征必须保留、允许改变哪些内容、哪些原画面元素必须排除；区分真正的相似性要求与本次创作要求新增的动作和内容。人设、服装、环境、说话声与动作的角色要清楚。保留/改变属于参考关系，不是对导演剧情的重新设计。
4. **detailed_description**：先用一两句英文确立风格，然后按导演实际 Shot 顺序描述。`[Shot 1]` 无时间戳，后续使用 `[Shot N] At MM:SS.mmm, ...`；写清画幅、主体位置、动作与反应、摄影机及可见环境、声音和台词原文，引用标签在真实作用处出现，不得仅描述抽象情绪。原文对白写 `<d>[Chinese] 原文。</d>`，同一实际发声者 `(S1)` 持续复用；画外音、口型封闭状态及跨镜说话关系按本地基础指南核对。只有确有实际支持时用 `<scenetrans>`、`<cutoff>`。若原始参考音频不可辨认，标明 `[unclear]`，不可猜对白。
5. **overall_soundscape**：整体环境声、动作音、人声空间位置和非语言音效，与 `detailed_description` 一致，不无依据地加入配乐或替换对白。
6. **non_diegetic_music**：本组织生成阶段不请求独立背景音乐，填写 `N/A`；剧情内可见/可听的现场音乐属于实际场景声音，不混同非剧情背景音乐。

## 参考关系与声源的常见误区

- 正在被直接编辑的视频才可以说“目标视频是原视频的编辑版”；单纯学习旧片的剪辑或运镜属于参考生成。
- 将音频波形真正复制到成片与借鉴某声音的音色不是一回事；不能因为提交了试听音频就承诺原音频会被直接复现。
- 在被直接沿用的 BGM 中出现的词句不应另设 `(Sx)` 发声者；具体人物、旁白或独立人声产生的台词才使用 `(Sx)`。
- 人物台词、歌词、可见文字保留原语言；镜头执行描述为英文，所有视听要求和 Shot 切点来自已审定导演资料。
- 正文中有真实对白却接口不支持时，标记声音待处理并按真实媒体工具能力交接，不将 silent preview 当成声画完成。

## 提交前确认

六段齐全；所有标签和参考文件已定义并实际绑定；持续时间与镜头时序一致；同一角色、服饰、状态和声线没有冲突；同一段落没有自相矛盾的留存/改变要求；`non_diegetic_music` 不请求额外配乐；插件回执与实际生成结果需要逐条核对。
