# AI 视频制作：从导演 Shot 到真实素材

本技能是**视频制作人的专业工作入口**。统合生产调度与 Prompt 编译流程；导演的 **Scene → Shot** 是正式叙事结构，**Clip 是技术生成任务及素材索引**，不得反过来改变导演的 Shot 数、切点、自然时长或剧本。

**输入**：工单、当前产物契约、已采用 director-plan（空间及视觉基准）、performance-plan（完整表演与状态）、shot-plan（镜头及动态时序）、asset-registry，以及已有 video-production（如有）。导演三份成果是生产依据；对白按 P4 原文片段与 Shot Plan 取用，发现具体缺漏或矛盾才定向回查锁定 Script，不默认通读剧本或重新解读剧情。BGM 不属于视频生成的输入依赖。

**正式输出**：组织 `video-production` 制作索引及其对应的当前 Clip 目录。实际媒体、完整 Prompt、必要参考绑定及关键帧同目录保存；索引维护实际采用顺序、Shot 覆盖与取用关系。内部尝试和归档自由管理，不回填导演文件。

## 执行规则

首次整集制作先执行 A，再逐 Clip 串行执行 **B → C → D → E**。已有有效成果时从受影响的阶段进入，局部返修与补充不机械重做整集。

1. 每个专业阶段是独立执行单元：实际读取该阶段列明的方法正文与已保存的前置结果，完成当前工作并通过独立文件写入或更新操作保存实际工作稿（D/E 保存真实生成与抽帧结果）；下一阶段实际回读，不在一次生成中同时完成相依设计。内部稿件格式、名称及目录由员工自主管理，不另设审批；本轮上下文中已读且仍适用的方法可复用。
2. 每个 Clip 独立完成 B → C → D → E，禁止提前编译整集最终 Prompt、批量或并行提交多个 Clip，以及使用循环脚本跨 Clip 调度生成（包括串行循环）。当前 Clip 必须完成真实生成、抽帧及索引更新后，才能进入下一个 Clip。脚本可完成当前单任务的等待/恢复、抽帧、媒体处理等机械操作。
3. 以已采用导演成果为计划依据；实际状态观察只有当前生产需要时触发。发现关键前序状态错误或无法可靠确认时定向处理，不把未读图或不确定状态当作已确认。

## A｜整体制作规划

**输入：** 工单、契约、导演三份成果、资产登记、已有 Production。  
**必读：** [生产原则](references/production/production-principles.md)、[制作索引规范](references/production/shot-execution.md)，核对本轮获准工具的真实时长与多镜能力。

按逐 P 表的 Shot ID 和衔接聚合同一连续 Shot，保留导演次序、自然时长及实际对白、动作覆盖；并行事件不重复计时。尽量保持同一 Shot 完整，兼容的相邻 Shot 可合并，受真实时长或模式限制才拆分，在自然承接处划分，不增加硬切。规划本轮全部 Clip 的编号、覆盖范围、时长、顺序及必要依赖，保存整体制作工作稿。不提前决定最终 Prompt 或参考绑定；有关状态依赖只标明后续需取得的实际依据。局部任务可复用有效规划。

**阶段完成：** 独立回读规划，对照已采用的 Shot Plan 与逐 P 表，逐 Shot 核对计划覆盖区间、自然时长、对白、动作及表演；覆盖完整、既定重叠不重复计入且顺序一致后，保存可执行安排供 B 承接。单次生成长度与质量档位只约束技术执行，不缩减获准的制作范围。

## B｜当前 Clip 生成准备

**输入：** A 已保存规划、当前导演表演及镜头内容、正式资产、E 已更新的实际 Production（首次无前段则以计划状态起始）。

| 步骤 | 前置依赖 | 必读方法 | 工作结果 |
| --- | --- | --- | --- |
| B1 当前内容与状态 | A、导演成果 | [生产原则](references/production/production-principles.md) | 当前 Shot/P 范围、表演与摄影时间、计划人物位置及关键状态 |
| B2 真实连续性 | B1、已有 Production | [连续性](references/production/continuity.md) | 明确需要继承或确认的实际状态；先定位索引，再按需读取对应前序帧，复用有效观察 |
| B3 模式与实际输入 | B1/B2、资产登记、实际工具说明 | [参考输入政策](references/prompt/reference-policy.md)、[H3 模式入口](references/prompt/minimax-h3.md)（使用 H3 时） | 当前生成模式、实际素材路径、用途及绑定安排 |

B1–B3 依赖顺序执行，每步保存结果并被后续实际回读；整合完成本 Clip 的生成准备稿。普通切镜不自动读图或套用旧整帧；血迹、伤损、持物、空间转换等需要实际依据时定位真正相关的前序 Clip，而非机械只取上一段。参考可能与当前空间或状态冲突时调整输入；新状态辅助图按需生成，不强制每段制作首尾帧。

**阶段完成：** 当前 Clip 的计划状态、必要实际依据、生成模式与真实输入已经明确；有阻碍当前生成的未决关键依赖时先定向解决或反馈主创。

## C｜当前 Clip Prompt 编译

实际回读 B 已保存结果，根据所选模式读取[Prompt 编译规范](references/prompt/prompts.md)，H3 按需读取[基础模式](references/prompt/h3-base-modes.md)或[全参考模式](references/prompt/h3-full-reference.md)，范例按需选读。将逐 P 时序换算至 Shot／Clip 局部时间，完整保留对应 P4 的原话、发声者、动作、反应、机位和切点；将明确的当前空间、姿态和实际继承状态落实到提示词。

保存实际 Prompt 和模型输入，独立回读核对时序、对白覆盖、参考标签、空间状态、模式及真实参数；发现问题回 B/C 定向修正。

**阶段完成：** 当前 Clip 的完整提交内容已保存且核对成立，交 D 实际执行。

## D｜单个 Clip 真实生成

实际回读 C 已保存的提交内容，使用当次获准插件的真实工具说明提交一个 Clip 并等待真实结果。结果未知时先恢复同一任务，保留必要真实回执；失败按原因回 B/C 或重试当前任务，不启动其他视频生成。不以任务提交成功冒充视频生成成功。

**阶段完成：** 已有真实输出文件及必要来源，交 E 核实；无法继续时记录实际阻碍并交主创。

## E｜抽帧与索引更新

实际读取 D 的真实结果，按[媒体操作](references/production/media-operations.md)确认视频存在、实际时长及来源，以当前表演和后续需要的状态变化选择实际抽帧时点，调用工具抽取必要关键帧。按[制作索引规范](references/production/shot-execution.md)保存当前有效视频、对应实际 Prompt、帧及来源并更新 Production，包括顺序、真实取用范围、Shot 覆盖及必要后期待办。索引随单个 Clip 完成即更新，供下一次 B 读取。

**阶段完成：** 本 Clip 的媒体、Prompt 与帧真实可定位，当前 Production 已保存。核对本 Clip 的实际时长和可取用区间是否满足计划覆盖；不足时回相应阶段处理，不能将计划区间登记为实际覆盖。不要求立即逐帧看图或完整视听验收；下一 Clip 的 B 根据需要读对应帧。随后才能进入下一 Clip。

本轮制作交付前，依据[制作索引规范](references/production/shot-execution.md)对照已采用的 Shot Plan 与实际媒体，核验全部获准 Shot 的实际取用区间是否完整覆盖其自然时序，处理遗漏、无依据的压缩、失效来源及区间冲突。覆盖未齐时续办缺口或向主创交接实际已完成范围及阻碍；只有整个委派范围覆盖完整，才可声明本轮视频生成完成，内容视听验收仍按岗位交接进行。

## 职责边界与检查

- 视频音频按当前组织和工单约定的范围生成；独立配乐意图交音乐与后期岗位。
- **技术 Clip 时长不限制导演 Shot 时长**。不可实现时可调整技术分段、输入与模型参数，但不得擅自增删导演硬切、缩短自然时长、删减对白与表演；真正需要调整镜头或表演设计时反馈主创交原作者处理。
- `GENERATED` 只说明**真实文件已生成、未完成内容验收**；口型、对白、人物数量、方向、动态及声音完整性由后期/主创据真实媒体核对。无能力完成必要声音时标记待办或 `BLOCKED`，不能冒充成片。
- **专业参考按任务按需读**：生产过程读 `references/production/`，Prompt/模型技术读 `references/prompt/`；按当前模型与实际生成模式选择正文和范例，不要求一次加载所有 H3 指南。
