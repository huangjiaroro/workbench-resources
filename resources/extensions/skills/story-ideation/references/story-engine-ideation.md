# 持续故事引擎创意：让一个设定不断产生不同事件

**用途**：在选题或故事候选阶段，辨别某个世界、人物组合或类型设定有没有持续生成故事的潜力。适用于研究员独立提出系列候选，也供编剧和主创打开新思路。**不等于**正式整季结构、分集大纲、剧集 Bible 或固定季数规划；这些由编剧使用独立 `drama-project` 的系列故事引擎、`drama-project` / `drama-writing` 的剧集结构 等技能落实。

## “概念吸引人”与“故事能持续”是两回事

- **概念**回答：这是什么有趣的设定？例如一座能让人交换职业身份的小镇。
- **故事引擎**回答：人物为什么会被迫在这个设定中反复作出不同选择？前一件事的结果又会怎样改变后一件事？
- **持续**不等于无限续集。有限集故事也可以有清楚的动力，并在关键矛盾解决后自然收束。

一个可用的故事引擎通常同时涉及：**触发事情的条件、必须行动的人、会反制的力量、可变化的代价、人物不能简单退出的原因**。它们可以松散，也可以相互叠加，无须写成公式表或固定章节。

## 五个构思杠杆

### 1. 反复触发，但不是重复同一事件

什么规则或处境让新问题自然来到人物面前？可能是工作、承诺、诅咒、家庭议题、公共责任或秘密交换。每次触发时改变至少一种实质条件：目标、参与者、风险、信息、规则解释、关键资源或人物之间的关系。

**反例**：每集都是陌生人上门提出同一种愿望，主人公同一种办法解决，人物关系完全不变。

**潜力改进**：相似来访者提出相反的正当利益，而前一个解决方案影响了后一个人的处境，主人公原本的原则开始被挑战。

### 2. 对抗不是只能依靠一个坏人

故事的反制力量可以来自另一人、制度、世界规则、经济依赖、人物自身盲点、互相矛盾的善意、无法兼得的目标。试着问：**即使反派暂时不出场，这个故事还会发生什么真正的矛盾？**

这不是禁止有明确反派，而是避免所有剧情只能等待反派偶尔发难。

### 3. 人物关系会给引擎补充燃料

持续创作中，同伴、家人、竞争者、客户和权力方之间的关系会变化。最好能看出：主角一次成功会让谁更依赖他、谁开始怀疑他、谁得到新筹码；失败则可能改变联盟和行动策略。

人物网络深入方法见 [人物关系创意](character-relationship-ideation.md)，不要把它替换成无关角色越多越好的复杂度。

### 4. 成功同样可能制造下一次冲突

如果故事仅靠主角一次次失败，容易变成机械受挫。试着想：这一集成功之后，新责任、新期待、新竞争或更大代价来自何处？有时主角越擅长做某件事，就越无法回到原生活。

因果积累是可选的。单元剧可以每集完成独立事件，只保留关系、世界或人物层面的累积；独立单元完全闭合也可以成立。

### 5. 引擎需要一个自然的结束条件

限定集数、短片、单季短剧不必为了续订无限拖延。询问：核心人物的矛盾在哪个选择后不再能以同样方式持续？哪个承诺兑现后作品应该结束？如果答案很清楚，可能说明适合闭合故事，而不是“引擎不合格”。

## 三种原创机制示例（仅供启发，不是模板）

**古风轻喜剧**：镇上有人专替乡民写“客气推辞书”，让人摆脱难以拒绝的人情。每个新委托不仅改变利益分配，还使代写者自己卷入被拒绝方的人情网。引擎是“拒绝的后果持续寻找新的承担者”，并非重复写信的动作。

**职场群像**：一个没有固定领导权的临时团队，完成任务就要重新投票分配资源。每次成功都会改变成员的筹码和联盟；制度目标与个人信任相互牵制。引擎是“协作产生权力重新分配”，不是无限开会。

**封闭悬疑**：一组人必须按周期交换有限证据才能获得通行权，透露真相可能同时牺牲某人的安全。不同信息的公开改变联盟和嫌疑范围；若核心秘密已经揭晓、所有人可以自由离开，故事便自然结束。

这些是原创思考演示，不应被复制进具体项目，也不要求每部剧都有类似的特殊机构或强设定。

## 在创意阶段怎样判断潜力

挑选少量**本质不同**的可发生情形进行脑内压力测试，而非按固定集数填写：

- 设定能否在不新增一条万能规则的情况下，推导出不同问题？
- 人物能否作出不同策略的选择，而不只是接受同一任务？
- 新事件是否可能改变关系、知识、利益或世界状态？
- 冲突是否依赖角色突然变笨或巧合恰好出现？
- 同一故事机制适合当前媒介和约定的叙事容量吗？
- 如果只有一个精彩事件，是否其实更适合短篇而不是系列？这也是有效结论。

研究员可在 `research` 的候选描述中简短说明“核心循环、可产生的不同冲突、自然结束点及未验证假设”；不是新增正式 `series-bible`、`episode-outline` 等文件。若用户已选方向，编剧在正式工作中用自身结构、人物和分集知识把故事写好，而不是把这一创意测试再机械执行一遍。
