# 人物关系创意：让人物彼此产生故事

**用途**：为研究员、编剧和主创探索故事可能性。这里处理的是“什么人物组合与矛盾值得成为一个故事”，**不是**要求研究员写正式人物档案、完整成长弧线、逐集关系表或对白。需要落实人物行为和成长时，编剧使用独立 `drama-project` / `drama-writing` 的人物冲突 等编剧专业技能完成。

## 从人际矛盾而不是身份标签开始

一个可创作的人物关系通常包含四种材料，按问题需要灵活组合，不必填表：

1. **各自想要什么**：欲望可以相同，获得方式却相斥；也可以目标相反，却被迫合作。要落到可观察的行动，不止“渴望被爱”“向往自由”等抽象词。
2. **为什么不能轻易离开对方**：亲情、利益、秘密、债务、共同任务、相互依赖、制度规则、空间限制、共同承担的后果。仅仅“性格不合”无法保证他们持续见面并发生冲突。
3. **双方各有什么真实道理**：为每一方提出一个能从其立场成立的理由、一个隐蔽代价或盲点。不是人人善良，也不是强迫反派洗白；是避免对手只负责犯蠢。
4. **关系中什么会改变**：信任、权力、控制权、秘密、责任、结盟、误解、利益分配、话语权中的至少一种；可以是微小改变，也可以不可逆。

创意深度不取决于人物背景资料有多厚，而取决于**这几个人同处一个问题时，是否必然作出不同选择**。

## 六种可移植的关系构思机制

| 机制 | 值得问的问题 | 产生的故事可能性 |
|---|---|---|
| **共同目标、冲突策略** | 两人都想救同一个人，却为何不能同意对方的方法？ | 合作越努力，内部矛盾越大 |
| **互补能力、互相牵制** | 谁能完成另一人办不到的事，同时又不愿交出控制权？ | 不得不结盟、彼此试探、合作反噬 |
| **爱与伤害共存** | 某人善意的保护，为什么恰好剥夺另一人的选择权？ | 无需典型坏人，也能产生难解冲突 |
| **同一秘密、不同风险** | 谁知道真相，谁以为自己知道，公开后谁受损最大？ | 情报交换、联盟转向、信任破裂 |
| **权力与依赖错位** | 表面强势的一方实际上在哪件事上受制于弱势者？ | 地位逆转、非对称讨价还价、黑色幽默 |
| **相同价值、不同身份** | 当两人都坚持“正确”，却负担不同责任时会怎样？ | 立场对撞、道德选择、关系变形 |

使用这些机制时，重要的是找到**一个属于当前世界观和具体人物的行动后果**，而不是把现成范式仅换名字、职业或朝代。

## 两种创意推演

### A. 从人物矛盾生成故事前提

- 选出一个矛盾，例如“擅长替别人争取权益的人，自己的权益却从不敢争”。
- 寻找能使这个矛盾**不得不行动**的关系：比如需要他教人拒绝的委托者、能随时撤销其身份的权力方、逐渐学会反抗的身边人。
- 给出反向压力：他教会的能力会不会反过来挑战他？一旦他成功，谁会失去利益？
- 再判断这是一部独立短片、单一故事还是可以持续产生事件的系列；不要先设目标集数后填情节。

### B. 从研究洞察生成原创候选

例如研究发现某职业高度依赖“互相打分”，不要直接复制现成职场剧。可以探索：谁握有评分权却需要别人保护？如何在合作中隐藏真正评分标准？制度改变谁的友谊和经济利益？

研究员应标注哪些部分来自有来源的现实观察、哪些是假设、哪些是自创的虚构关系；不要把创作推演伪装成事实。

## 关系潜力如何自检

- **相遇的必要性**：把其中一个人换成普通路人，矛盾是否几乎不变？若是，关系还没产生独特作用。
- **行动的必要性**：人物能否仅靠解释、道歉或搬走完全解决？若作品希望有持续冲突，需要找到阻碍这种简单解法的可信条件；一次性短篇则不必强行延长。
- **变化的可能性**：一次事件之后，谁更信任谁、欠谁什么、获得什么筹码？如果永远只重复互骂，问题通常在关系机制。
- **双向合理性**：每一方是否拥有自己的目标和约束？不用证明双方道德上等价，但不能只能靠降智推动。
- **观众期待**：观众是在等“秘密暴露”，还是等“看似同盟的人究竟作何选择”？优先寻找行动驱动的期待。

这些是**构思问题的思考角度**，不是通用验收清单，也没有必须达到的关系人数或矛盾条数。创意成熟到足以比较、讨论或支持下一步写作时即可停止。

## 与正式编剧工作的边界

本参考的交付通常是一段有戏剧作用的人物关系设想、必要的核心矛盾和可继续发展的方向。研究员写入 `research` 的原创候选中；编剧若采用并进入正式开发，则依据组织 `artifacts.yaml` 把完整人物动机、选择、成长与剧情落实到正式成果。**概念相通，专业方法和文件归属不重复。**
