# 故事创意构思｜专业资料调度（index.md）

本页相当于 `story-ideation` 的内部 Skill 入口。识别本轮究竟是探索前提、重建人物关系、构造持续冲突、借鉴一部作品，还是从戏曲的叙事机制得到灵感，再按对应专题 `index.md` 进入。**不是完整理论清单的必读顺序**。

## 调度路径

1. 从已确认设定和当前问题确定要探索的变量（人物欲望、冲突、关系、类型承诺、叙事机制或候选差异）。
2. 优先选择匹配的单个专题索引；需要两种不同视角时才组合阅读方法与案例。
3. 阅读相关 `craft.md` 章节，或直接到表格/案例资料找证据；不能读完一份方法概述就把专业查表跳过。
4. 产出真正不同的创意方案，比较因果、角色选择、可持续性和表达效果；不要强迫每个任务都生成若干份额外文档。

## 前提与类型方法

本索引按创意问题选择专业参考。需要深入某一方向时，再读取对应方法及其引用资料。每份方法包含可操作的创意步骤及适用条件；只按本次创意问题选用，不把候选推演视为正式剧本交付。

| 创意问题 | 优先读取 |
|---|---|
| 故事前提、戏核、主题、角度、反讽钩子、一句话故事 | [sw-premise-theme](methods/sw-premise-theme/index.md) |
| 类型承诺、类型节拍、类型反转、类型混合 | [sw-genre-anatomy](methods/sw-genre-anatomy/index.md) |
| 不知从哪里开始构思或重复既有套路 | [创意思考](creative-thinking.md) |
| 构思有张力的人物搭配、依赖、权力、秘密、利益与关系矛盾 | [人物关系创意](character-relationship-ideation.md) |
| 判断一项设定能否持续产生不同事件、怎样形成长线冲突机制 | [持续故事引擎创意](story-engine-ideation.md) |

**适用性提醒**：资料里可能同时介绍互不相容的理论或某种媒介的行业样例。选择解释当前作品最有帮助的方法，不将其页码、幕数、结构百分比、固定故事数量或输出模板上升为通用规则。

## 跨作品与风格案例

以下资料用于**可选的创作灵感和研究对照**。需要具体作品证据时，仍须查验原作品或可靠来源；引用下述分析不等于已实际看过作品。不得换名复刻独特情节。

| 希望探索的叙事可能性 | 可选专业参考 |
|---|---|
| 经典美国电影中的故事结构、人物转折和冲突 | [美国电影案例](case-studies/sw-american-case-studies/index.md) |
| 剧集分集节奏、悬念、人物关系与长线发展 | [剧集案例](case-studies/sw-series-case-studies/index.md) |

| 韩国与法国的类型、人物和作者表达 | [韩法编剧方法](case-studies/sw-korean-french-screenwriting/index.md) |
| 日常生活的潜台词、人物关系与非显性高潮 | [契诃夫戏剧](case-studies/chekhov-dramaturgy/index.md) |

**案例阅读路径**：先明确本轮需要研究的创意机制，再看对应作品的专业分析、代表例证与可迁移步骤；只选确实有帮助的操作去做创意试验，不要求重写成某位作者的作品。

**不把案例当模板**：真实作品的时长、页码、工业写作流程、导演风格或固定节拍仅在相关媒介/创作目标匹配时借用。研究员可分析创意机制，编剧借助创意 Skill 提炼思路；正式编剧方法通过已安装的独立编剧专业技能落实。

## 戏曲与传统叙事资源

当涉及唱白节奏、视点/行当、信息差、情境反转等可迁移机制时，进入 [传统戏曲导航](traditional-theatre/index.md)，再按板腔体、曲牌体或剧本案例选择，不将戏曲技术规条强加给影视剧。
