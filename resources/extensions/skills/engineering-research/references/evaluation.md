# 开源方案评估矩阵

| 维度 | 核对方式 |
| --- | --- |
| 功能匹配 | 精确指出满足需求的 API、源码文件或可运行示例 |
| 项目活跃度 | GitHub Release、提交、Issues 处理（标注查询日期） |
| 许可与合规 | LICENSE 文件、仓库依赖及商用边界，未核对记未知 |
| 集成代价 | 运行时、SDK、进程、协议、跨语言桥接 |
| 认证与安全 | 登录方式、凭证存储、工具权限、沙箱边界 |
| 状态可靠性 | 断线恢复、幂等、重复执行、会话持久性 |
| 运行与维护影响 | 检查对现有服务、部署环境、用户数据及其他开发任务的影响，使用独立验证环境 |
| 验证等级 | 文档证据 / 源码证据 / 已运行 PoC / 项目真实集成验证 |

仅比较真实证据。缺证据就标未核实。不要因为 GitHub star 多就判定可直接集成。
