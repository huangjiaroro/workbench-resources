# 三、 场景多视角宫格图 Prompt 模板 (16:9 横向)

### 模板结构

```text
场景设定宫格图，[场景名称]，[全剧美术风格]，同一场景在所有视图中保持一致。
【版式与排版】
16:9 横向构图，纯净浅灰或白色背景，专业场景设计稿排版，类似角色设定图的多视角展示形式。
画面包含清晰中文标题：[场景名称]。
左侧为一张大幅主视角总览图，展示场景整体氛围、主体结构、前中后景关系与核心视觉焦点。
右侧为 4 张小幅场景视图，分别包括：
1. 45度斜角全景图，展示空间纵深与结构层次
2. 正面结构图，清晰展示主体正立面
3. 侧面结构图，展示场景侧面轮廓与空间厚度
4. 俯视布局图，展示整体平面布局与区域分布
【场景视觉 DNA】
环境与结构：[建筑/房间结构描述]
材质与细节：[墙面、地面、主要家具与标志物]
光影与色调：[灯光氛围与配色]
【限制要求】
无人物，纯场景设计，所有视图为同一场景、同一设计、同一配色，与角色出图风格 100% 绝对一致。
```

---

实际 Prompt 应替换所有占位并忠于当前已确认设计。[共同负向约束与质量检查](../image-prompt-templates.md)以及真实生图、核对、登记操作详见[图片生成](../image-generation.md)；本文件只负责本类型的专业版式与特有约束。
