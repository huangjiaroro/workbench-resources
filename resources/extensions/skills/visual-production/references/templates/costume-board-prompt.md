# 二、 服装设定板 Prompt 模板 (16:9 横向 - 新增换装资产)

### 模板结构

```text
服装设定图，[全剧美术风格]，[所属角色][服装款式套件名]，展现指定角色在特定场景下的换装套件。
【版式与排版】
16:9 横向服装设计稿，纯净浅灰背景。画面包含清晰中文标题：[服装套件名称]。
左侧 1 张大幅面布料材质与立体剪裁特写图；
右侧 2 张穿在模特杆或人台上的正面与侧面完整服装展示图。
【服装视觉 DNA】
款式版型：[如：工装夹克 / 商务三件套西装 / 告白白色连衣裙]
材质面料：[如：防风牛仔 / 精纺羊毛 / 蕾丝雪纺]
配色与纽扣：[主色调与扣具装饰细节]
【限制要求】
无头部，仅展示服装款式、裁剪与材质，同全剧画风 100% 绝对保持一致。
```

---

实际 Prompt 应替换所有占位并忠于当前已确认设计。[共同负向约束与质量检查](../image-prompt-templates.md)以及真实生图、核对、登记操作详见[图片生成](../image-generation.md)；本文件只负责本类型的专业版式与特有约束。
