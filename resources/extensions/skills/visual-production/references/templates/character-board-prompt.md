# 一、 角色设定板 Prompt 模板 (16:9 横向 - 纯粹人物无随身道具)

### 模板结构

```text
角色设定图，[全剧美术风格]，[性别][年龄段][角色身份]，同一角色在所有视图中保持一致。
【纯粹角色设定，剥离任何非常态随身道具，无背包，无手持武器，无挂件】
【版式与排版】
16:9 横向角色设定板，纯色干净浅灰或白色背景，专业角色设计稿排版，画面包含清晰中文标题：[角色名称]。
左侧约 40% 画面：上方为角色名称大字标题；标题下方为短信息栏，分行写身份、气质、核心特征、主色调；左侧主体是一张大幅面部或胸像特写，展示五官、发型、头饰、表情和服装上半身材质。
右侧约 60% 画面：三张同一角色全身视图横向排列，分别是正面、侧面、背面；三张全身视图脚底对齐，比例一致，底部用简洁中文标注“正面”“侧面”“背面”。
所有视图必须是同一角色、同一年龄、同一基础服装、同一发型、同一配色。
【面部设定】
五官与脸型：[如：清秀冷艳、眼神坚毅、肤色冷白]
眼睛与表情：[瞳色与表情特征]
【发型设定】
[发色]，[发型及发饰]
【基础服装设定】
[服装风格]，[主色调]，[袖子与材质细节]，[裤装/裙装与鞋子]
【画风与质感】
[全剧画风]，high quality，材质清晰，阴影自然，专业角色设定板
```
