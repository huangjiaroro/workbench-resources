# 四、 道具设定宫格图 Prompt 模板 (16:9 横向 - 一图一道具)

### 模板结构

```text
道具设定宫格图，[单道具名称]，[全剧美术风格]，同一道具在所有视图中保持一致。
【严格“一图一道具”，画面中只展示这一个独立道具，绝不混合其他道具】
【版式与排版】
16:9 横向构图，纯净浅灰或白色背景，专业道具设计稿排版。画面包含 5 个视图：左侧 1 张大幅主视图，右侧 4 张辅助视图。
左侧大图：主视图，完整展示该单一道具整体造型、轮廓、材质、装饰与配色。
右侧第 1 张：侧视图，展示道具厚度、立体结构与侧面轮廓。
右侧第 2 张：顶视图，展示顶部结构与形体关系。
右侧第 3 张：局部细节特写图，展示纹样、材质、镶嵌与机关细节。
右侧第 4 张：尺寸参考图，展示实际比例关系。
【道具视觉 DNA】
材质：[材质描述]
配色：[主色调与点缀色]
纹样与造型：[结构与细节描述]
尺寸感：[巴掌大小 / 腰间悬挂 / 单手持握]
```

---

实际 Prompt 应替换所有占位并忠于当前已确认设计。[共同负向约束与质量检查](../image-prompt-templates.md)以及真实生图、核对、登记操作详见[图片生成](../image-generation.md)；本文件只负责本类型的专业版式与特有约束。
