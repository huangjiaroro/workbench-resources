# 设定板 Prompt 共通要求

根据已采用的全剧画风和当前资产设计编写完整中文 Prompt；不要把占位或示例文字提交给生图工具。具体结构、视图与字段按相应类型规则执行：

- [人物](templates/character-board-prompt.md)
- [服装](templates/costume-board-prompt.md)
- [场景](templates/scene-board-prompt.md)
- [道具](templates/prop-board-prompt.md)

四类设定板都使用 **16:9 横向**，背景简洁，同一设定板各视图的主体身份、结构、材质与配色应一致。不要把临时伤痕、天气和运动状态固化为新的正式设计，除非上游已确认它们是稳定变体。

**通用负向提示：** 避免杂乱背景、无关物体、错乱标签、缺失必需视图、跨视图身份或结构不一致、额外手脚和畸形。人物、道具、场景的专有排除项由对应规则决定，不把一种类型的限制错误施加到另一类型。

出图后按实际图片检查必需视图、裁切、标注与一致性，合格后登记真实路径和检查结果。
