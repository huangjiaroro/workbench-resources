# 全剧基础素材与单集定向补缺规范

本文件负责正式视觉资产的实际建库与补缺路径，正式/临时状态判定遵循 [asset-principles.md](asset-principles.md)。完整组织阶段顺序由组织 PLAYBOOK 维护。

## 一、现有设计优先与真实登记

先查组织的唯一 `asset-registry`，复用仍满足设计与实际媒体要求的既有条目。不为普通临时状态建立第二套资产，也不把未生成的设计说明当真实素材。具体字段、媒体真值及登记规则按[登记契约](asset-contract.md)执行；本文件只规定**何时需要创建或补齐设计**。

## 二、全剧基础建库（整体设计采用后）

依据已采用的蓝图、Canon 和相关承重单元，筛查已经确定的主要人物、独立服装设计、核心空间、重要道具与角色音色。出场频次可帮助判断优先级，但不是唯一素材准入标准。已有相符设计复用，未确定的剧情细节不预制。

按四类标准生成真实 16:9 图片、逐张检查后登记。空间之间的层级与人物重大形态变化使用 `base_asset_id` 或同类关联字段建立联系。对实际需要稳定发声身份的人物，声音选择和采用须有真实试听依据；无发声需求的人物不强制提供音频。

## 三、单集常规补缺（锁定正文后）

从主创已采用锁定的 `episode` 产物与实际素材登记簿检查：

1. **独立人物或重大形态**：新增具有稳定视觉身份的人物，或角色本体外观结构发生根本变化的新形态（如变成机械装甲生命体）。应建立相应正式人物设定板，并与基础人物关联。
2. **独立服装**：新增需要固定剪裁、材质、配色的换装、制服、盔甲等。通常新服装独立在 costume 类型登记，角色本体不因换衣而重新建人物设定板。
3. **独立空间**：已有客栈外观或大厅不代表客房、走廊、密室已有设定；具有独立空间结构与布局的房间/区域，按 scene 类型单独设计并与其所在大场景关联。
4. **重要道具**：存在独立造型、关键识别或稳定复现要求的武器、信物、道具等，即使只在一场戏出现也可以建立正式道具设定板。

不因受伤、沾血、淋雨、衣物临时撕裂、人物姿态、表情、镜头光照、临时持物而创建新的正式素材。此类状态交导演计划和真实关键帧继承。普通不承重的背景陈设及无独立设计需求的物品不强制单独建图。

## 四、导演期间定向追加（场景、表演与 Shot 规划时）

导演发现剧本常规筛查无法预判的独立视觉资产需求时，应提出具体场次/Shot、拟新增资产类型、设计与现有资产的关系、为什么无法复用以及预期用途。视觉设计师核对所涉故事事实与已有设定后：

- 属于真实新设计需求：生成该资产唯一标准设定板，检查并登记，向导演交回可引用的 `asset_id` 和实际图片路径；导演更新受影响的 `director-plan`、`performance-plan`、`shot-plan` 及相应素材引用。
- 属于临时剧情状态或现有资产即可覆盖：说明沿用的正式资产和状态继承建议，不另建设定板。
- 与已锁定剧本或美术设计冲突：说明冲突位置交主创处理取舍，未经授权不覆盖现有权威设定。

**不要求导演开始前备齐所有未来镜头细节，但相关 Shot 进入实际生成前，其必须引用的正式资产需要真实存在。** 已就绪的独立场次不因其他素材缺口而一律停工。导演设计与素材出图可在直接依赖关系下往返，不新增固定的第二次全剧素材审核关口。

## 五、出图与登记交接

四种类型的设定板具体版式、提示词和视觉质检以[图片生成](image-generation.md)及相应类型规则为准。正式采用的图片和稳定关联写入组织 `asset-registry`，登记方式见[登记契约](asset-contract.md)。本文件不重复维护版式或字段清单。
