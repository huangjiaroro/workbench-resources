# 🎨 视觉资产提取原则与规范 (Asset Extraction Rules)

本文档定义了从微短剧故事大纲、全剧梗概或分集剧本中提取人物、场景和道具资产的具体判定标准与 Visual DNA 格式。

---

## 一、 资产筛选三大原则

并非剧本中出现的所有名词都需要提取为视觉资产。正式资产用于锁定独立视觉设计；剧情中的暂时姿态、伤痕、血迹、衣服破损、光照等状态交导演描述与真实视频关键帧记录，不单独建立正式设定板。判断依据如下：

1. **长期生产价值 (Reusable Value)**：在全剧多集重复出现、承担核心剧情或必须在 AI 画面中保持高度视觉一致性的对象。
2. **独立视觉特征 (Visual Distinctiveness)**：具有明确的外观、造型、材质或色彩特征，需要明确设定图指导生成者。
3. **排除项 (Exclusion Filter)**：
   - 无稳定复现或承重用途的路人、临时地点和普通日用品不单独出图。
   - 单次出现却需要固定外形或独立空间结构（例如客栈中的一间独立客房、仅本集出现的关键法器），仍按具体用途提取；不以出场次数为唯一门槛。
   - 已有人物发生本体结构性变身应创建关联正式形态；普通换衣建服装资产；临时战损、表情、动作与持物状态不创建新人物资产。

---

## 二、 四类资产的 Visual DNA 完整规范

每项资产需要足够具体、可复现的稳定 Visual DNA。下列字段是不同类型的检查维度；**与当前主体不适用的字段明确填 `N/A` 或说明替代识别特征**（例如无毛发的机械生命体、无固定人类性别的异类角色），不得为了填满表格编造原文事实。适用的重要字段不能模糊，缺失的承重信息应标记待确认。

### 1. 人物 (Character Visual DNA - 纯粹人物无随身道具)

| 字段名 | 含义说明 | 示例 |
| :--- | :--- | :--- |
| `race` | 种族/身份属性 | 人族 / 骨妖 / 仙灵 / 机械改造人 |
| `gender` | 性别 | 女 / 男 |
| `age` | 外貌年龄感 | 18岁左右 / 三十岁出头 / 千年古妖貌如少女 |
| `appearance` | 五官与面部特征 | 肤色冷白，凤眼微敛，唇色如血，面容清秀带病态 |
| `build` | 身材体型 | 纤细修长，脊梁挺拔，稍显孱弱 |
| `hair` | 发型发色 | 乌黑长发盘成精细民俗双鬟，配红绳扎发 |
| `eyes` | 眼睛瞳色与眼神 | 深邃黑瞳，眼神坚定中带着一丝宿命感悲凉 |
| `distinctive` | 2-4个稳定识别特征 | 眼神坚定、高马尾发型、无随身包/武器道具 |

### 2. 服装 (Costume Visual DNA - 新增独立换装资产)

| 字段名 | 含义说明 | 示例 |
| :--- | :--- | :--- |
| `owner` | 所属角色 | 林舟 / 姜禾 / 外婆 |
| `scenario` | 适用剧情场景 | 乡村日常 / 商务法庭 / 告白浪漫 |
| `style` | 服装样式与版型 | 工装夹克 / 商务三件套西装 / 白色蕾丝长裙 |
| `fabric` | 材质与质感 | 牛仔帆布 / 精纺羊毛 / 真丝雪纺 |
| `palette` | 主色与点缀色 | 卡其色配米白 / 藏青配墨黑 / 象牙白 |
| `details` | 纽扣/口袋/裁剪细节 | 双排扣金属件，立体贴袋，收腰褶皱 |

### 3. 场景 (Scene Visual DNA)

| 字段名 | 含义说明 | 示例 |
| :--- | :--- | :--- |
| `environment` | 空间环境性质 | 室内古风绣房 / 深山老林破庙 / 赛博地下市场 |
| `layout` | 空间布局与纵深 | 前堂为木质绣案，后屏风为祖师牌位，两侧挂满民俗刺绣 |
| `architecture` | 建筑与结构风格 | 明清中式木结构，雕花木窗，飞檐斗拱，略显阴森 |
| `lighting` | 主光影与气氛 | 深夜青幽冷光为主，桌前一对红烛泛着微弱暖光 |
| `palette` | 主色调 | 墨绿、青灰、朱红点缀、暗金 |
| `landmarks` | 核心视觉地标 | 中央巨大的紫檀木老绣架，悬挂未完成的玄色九幽图 |

### 4. 道具 (Prop Visual DNA - 一图一道具)

| 字段名 | 含义说明 | 示例 |
| :--- | :--- | :--- |
| `category` | 道具类别 | 武器 / 佩饰 / 法器 / 符咒 / 器具 / 随身皮具 |
| `material` | 材质构成 | 寒铁镀金、做旧皮革、复古纸质 |
| `shape` | 造型形体 | 单一独立物品，长三寸的细长绣针 / 单一牛皮包 |
| `color` | 主色与点缀色 | 针身漆黑如墨，针尖泛着刺眼猩红 |
| `markings` | 纹样符印 | 针身刻有微型九幽冥文 |
| `condition` | 状态与尺寸感 | 锋利无比，巴掌大小，独立展示，严禁混合多个道具 |

## 三、 当前项目的登记方式

以上筛选原则和四类 Visual DNA 字段以本方法为准。按本次授权选择全局基础或单集补缺范围，先复用已采用且适用的素材，再补缺。对适用字段给出具体、稳定且可辨认的特征；不适用字段注明 `N/A`，不能以编造外形、性别或年龄填空。根据已知设定与获准的美术设计补足未定细节，遇到锁定事实冲突先定位并反馈。

使用 [asset-registry-template.md](templates/asset-registry-template.md) 更新组织唯一素材登记索引及对应 design.md，不新增候选索引或第二份全剧资产报告。每项保留稳定编号、名称、提取依据、Visual DNA、实际图片与 Prompt 及检查记录。服装单列并链接所属角色；角色音色和试听记录留在角色设计。
