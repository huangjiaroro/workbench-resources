# 角色声音与试听

角色音色可在全局基础素材阶段确定，单集仅补新增角色或必要变体。根据当前身体年龄、音域、质感、语言/口音和说话方式选择声音；重要形态变化说明适用范围。已有且适用的参数、文本和真实试听文件齐备时复用，缺文件不算就绪。

## 角色声音辨识

1. **常驻核心角色音色独占（Exclusive Voice Identity）**：主角与核心常驻角色使用专属声音身份；临时配角选择其他音色或生成基底，以保持角色辨识；
2. **实际发声配角的辨识准则**：只有确实需要对白、旁白或稳定声源身份的小配角，才按剧情作用从可用声库选择相符音色并在必要时试听，注意不与核心常驻角色混淆；无台词、无发声需求的路人和背景人物不要求独立音色或试听。临时配角无需人人定制独立模型，复用非核心音色须不造成听觉身份混淆。

## 音色生成与试听验收

核对实际音色查询与语音合成能力的真实授权/连接与输入。查询实际可用voice_id，选少量有依据的候选，以短而不新增剧情事实的文本试听；配置存在不证明效果。本流程通过已有音色选择与 TTS 试听确定声音身份。

将采用的真实试听文件放入对应人物正式目录；人物 design.md 注明提供方、voice_id、模型、实际语速/音量/音高/语言、试听文本、真实路径或 mediaId/hash 和收听情况，登记索引可引用该试听文件。单人清晰无配乐；实际听清晰度、角色匹配、语言和彼此辨识。文字、波形或工具成功不代替收听。

交付角色音色配置、真实试听文件、声学先验以及适用范围。试听文本用于声音身份识别；角色声音配置与音乐演唱音色分别维护。
