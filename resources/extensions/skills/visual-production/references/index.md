# 视觉设计与素材：专业方法索引

本索引是 `visual-production` 的**模块级 SKILL / 唯一专业调度入口**，不是文件目录清单。从当前任务和已有真实资产出发，按需打开所需方法；不是必须依序执行的独立生产流程。正式成果类型、采用权限和存放路径以当前组织契约为准。

## 适用与执行路径

- **适用情境**：全剧基础素材设计、单集定向补缺、现有素材匹配与更替、角色稳定音色、正式资产登记。
- **专业原理**：稳定身份与临时剧情状态分开；先复用真实已登记资产，再补充必要的可验证设计，不把尚未出图的草案当正式素材。
- **核心路径**：核对上游与资产登记 → 判断缺的是独立资产还是临时状态 → 选择对应设计规范与 Prompt 模板 → 真实生成、检查一致性 → 回写唯一登记簿。
- **边界**：不因为模板多就同时生产所有类型；不修改导演计划或把技术视频 Prompt 当成资产设定板 Prompt。

## 按具体素材任务选资料

| 当前任务或问题 | 必读专业方法 | 深入参考与使用边界 |
| --- | --- | --- |
| 判断要不要建正式资产、稳定设计与临时剧情状态如何区分 | [资产原则](asset-principles.md) | 定义范围与 16:9 标准，不在此维护登记字段或分集生产步骤 |
| 从蓝图或 EPxx 识别正式人物、独立空间、服装、承重道具 | [资产提取与 Visual DNA](asset-extraction-rules.md) | 描述应明确到可复现，确实不适用的非人字段允许 `N/A`，不要编造 |
| 全剧基础设计、单集补缺、导演定向新资产 | [素材设计与补缺](asset-design.md) | 根据当前直接依赖处理，复用已有正式资产，不重复全剧建库 |
| 生成真实设定板、选择对应提示词并核对质量 | [出图方法](image-generation.md) | 读取[共通 Prompt 约束](image-prompt-templates.md)，再按类型选规则 |
| 人物设定板（正/侧/背及面部身份） | [人物出图规则](templates/character-board-prompt.md) | 使用角色视觉 DNA，不把普通姿态/损伤作为正式变体 |
| 服装套件设定板 | [服装出图规则](templates/costume-board-prompt.md) | 独立服装造型关联人物，不重建人物身份 |
| 场景空间结构与地标设定板 | [场景出图规则](templates/scene-board-prompt.md) | 注意独立房间和门窗结构，与导演空间规划核对 |
| 承重道具的形态与尺寸参照 | [道具出图规则](templates/prop-board-prompt.md) | 保证同一道具跨视图一致 |
| 角色确实需要稳定发声身份时选择并试听音色 | [声音选择](voice-casting.md) | 无发声需求角色不强制建音轨；实际试听才算就绪 |
| 导演 Shot 对正式图像、服装、场景、道具的引用是否匹配 | [Shot 素材匹配](asset-matching.md) | 只核实设计与媒体是否适用，H3 Prompt 编译属于视频制作人 |
| 正式登记、真实媒体证据及当前产物字段 | [登记契约](asset-contract.md) | 只维护组织中的 `asset-registry`，不建立并行登记簿 |
| 需要查看登记条目写法 | [登记模板（只读范例）](templates/asset-registry-template.md) | **不要在本模板文件写实际资产**；将必要条目填写到组织正式 `asset-registry` 中 |

**选用原则**：针对单个问题可直接进入对应方法；必须核对稳定身份、真实媒体与引用范围，但不因索引有多项而强制每次遍历全部文档。
