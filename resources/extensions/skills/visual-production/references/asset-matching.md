# Shot 正式素材匹配

输入是本次获准准确版本的导演 shot-plan、director-plan 与 performance-plan 中的场景空间和计划状态、锁定正文、真实 asset-registry 及需要的设计/媒体。先读取实际条目与附件，不凭素材名称、聊天摘要或旧图存在推断已经齐备。只核对正式素材是否满足 Shot 的视觉设计及真实媒体需求，不改写对白、表演、时长、情绪、状态或连续方式；具体模型 Prompt 编译由视频制作人负责。

## 匹配依据

1. 按当前人物身份或重大形态、独立空间结构、服装设计和道具外观选择正式条目；临时伤痕、污渍及姿态按[正式素材与状态边界](asset-principles.md#二正式素材与临时剧情状态的界限)使用状态描述和相应实际依据承接；复用稳定 asset_id，并核对关联 base_asset_id。素材 ID、设计文件路径和媒体哈希分别记录，不能互相代替。
2. 每个引用写真实类型、稳定名称、asset_id、适用变体、用途和采用的精确设计/媒体。核对实际图片文件及哈希，不能把 registry 的计划路径当作图片引用。
3. 角色、空间、关键道具与真实音色按当前 Shot 或 H3 生成任务用途绑定。音色只有存在适用身体的真实音频及试听依据时才就绪；voice_id 或配置不是音频文件。Subject/Picture/Audio 上传标签在 Prompt 编译时按真实输入顺序建立，不在匹配阶段编造编号或 URL。
4. 临时姿势、机位、普通背景陈设、天气与没有独立参考需求的普通手持物留在表演说明。只出现一次却承担证据、反复需要稳定复现的物件或跨多片的空间仍须匹配，不能以出场少为由忽略。
5. 关键对象不存在，或已设计但缺少当前必要图片/音色时，返回 NEEDS_ASSET，列出来源、名称、类型、受影响 Shot 和为何需要独立参考。未就绪项放在缺口清单，不填 asset_id=待补、相近素材、假媒体或占位标签。
6. 设计或实际图片与当前表演冲突时返回 NEEDS_RECONCILIATION，定位事实和媒体证据，交主创协调；不能改绑定掩盖冲突。单视角补图不能替代尚未完成的基础设定板。

匹配完成只说明真实引用适用，不证明 Shot 设计已通过审查或实际视频已实现设计。确实不需要稳定素材引用时可写无，并说明范围；不能用无绕过承重缺口。实际生成前解决当前条目的关键缺口与跨段边界，并核对工程完整有序条目。

## 更新与恢复

只对当前修订的设计与制作任务补充引用。已完成 Shot 对应的制作素材 要改变引用时，交主创确认影响并定向更新，复核直接前后关系。来源正文、设计或图片变化后逐项比较用途，已适用的绑定不重建，失配的引用与实际续接需求重新待核对，并通知视频制作人重新核对相应 Prompt 输入。
