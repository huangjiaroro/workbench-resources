# 叙事审核：正文、状态、因果与知情

用于组织安排的单集正文与 State 专业审核，以及负责人明确委派的叙事疑点复核。完整单集审核先按下节取得输入，具体疑点只读取对应原文及真正相关的设计与状态；不将局部复核扩写为整集通过结论。

## 单集正文与 State 审核

以当前有效 Canon、被审单集的完整 Script 和对应 State 为主要输入。Canon 提供已确定的稳定事实与规则，Script 确定本集实际演出的动作、对白和事件，State 应忠实记录后续需要继承的结果；未来规划、角色误信和客观事实须区分。相关 Blueprint、前集 State、设计稿或故事单元仅在核对具体依赖时补读，设计意图不能覆盖正文已经发生的事实。

完整阅读正文和 State，围绕三类问题一次性形成反馈：

1. **正文与已确定设计的冲突**：世界规则、人物身份、已发生事实或明确保留决定是否被无依据改变；有意隐瞒、角色谎言和未揭晓真相不能仅凭表面差异判作矛盾。
2. **State 与正文的不一致**：是否漏记承重事件或知情变化，添加未演出的昏迷、关押、转移和物件处理，把推断写成事实，或将正文已说出、已发生的内容记为未发生。正文未交代的结果保持未确定，不能为便于续写自行补齐；认为必须补足时指出正文缺口。
3. **正文自身的关键因果与连续性缺口**：行动是否具备条件，重要信息由谁何时取得；人物如何应对，原始危机是被解决、转化还是保留，转折与退出状态是否有成立依据。新事件出现、主角获胜或作者自评“高智商”，不能代替对手目标和反制的实际处理；有意留下的悬念不强求当集解答。

每项反馈给出准确场次或原文位置、冲突两端或成立依据、实际影响及需要解决的问题。确定错误、需要解释或补证的疑点、可选创作建议分别标明；不为凑意见要求换风格、加反转或重写已采用方向，不直接替作者编修法。未发现实质问题时如实说明，报告实际检查范围。

反馈交负责人协调，原编剧修订正文并同步受影响的 State 与设计。是否追加审核由组织和负责人决定；本方法不要求作者每改一版就重启完整审核。受委派核对修订时只检查原问题及实际受影响的依赖，复用未变化的有效结论。

## 按当前成熟度判断

候选或初稿只判断当前问题所需的故事条件，不要求未展开内容具备定稿细节。修订稿重点确认目标问题、保留决定和实际影响；拟定稿按该专业问题所需的精度核验。具体场景实现允许作者自主选择，不以某一种结构或个人偏好作为唯一答案。

## 复杂因果与跨集信息

还原与疑点有关的事件顺序、行动条件、角色所知、观众获知及客观事实，追到可定位的正文、锁定设定和必要机制依据。角色猜测不等于事实，未来计划不等于已发生事件；关键真相也可能在尚未揭晓前已被锁定。State 用于定位和承接，涉及具体场面或原话的争议仍须回到正文。

检查行动是否早于信息来源、线索能否支持结论、铺垫与回收是否对应，以及改动是否使原成立条件失效。正文需要呈现观众理解因果所需的信息，无须复述机制文档全部论证。复用成立条件未变的既有机制结论，有新矛盾时再定向核验受影响部分。

## 从症状定位根因

对“不够搞笑”“冲突没有升级”等反馈，依据实际文本区分：

- **症状**：哪段动作、对白、重复或信息安排没有实现预期效果。
- **直接成因**：人物目标、策略、反制、信息变化、节奏或语言是否有具体缺口。
- **深层根因**：是否需要回到人物关系、故事前提或世界条件校正；上溯须有原文证据。
- **影响与建议**：指出需要作者在哪个创作层级修复，以及实际受影响的范围。

例如角色连续三次以同样理由恳求、对手三次同样拒绝，可以据此指出策略没有升级；一段刻意僵持的短戏则未必有错。区分因果不成立、有依据的效果风险与可选创作建议，不直接改写正式稿。

需要独立推演案件、游戏或骗局的成立性时，按问题读取[承重机制](story-unit.md)；涉及实际空间、动作和声音表现的疑点时，读取[视听专项复核](video.md)。
