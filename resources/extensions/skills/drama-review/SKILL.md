# 独立专业复核

当负责人委派需要独立专业判断的问题或对象时使用。常规成果自检由作者负责，审阅、验收和采用由负责人负责；本技能按工单核验指定对象和范围。

先读[共同复核方法](references/reviewer.md)，再按问题选择资料：

| 需要独立核验的问题 | 按需读取 |
| --- | --- |
| 单集正文是否符合已确定设计，State 是否忠实于正文，关键因果与人物知情是否一致 | [叙事审核](references/narrative-diagnostics.md)的“单集正文与 State 审核” |
| 整体方案、表演设计与 Shot Plan的剧本覆盖、戏剧意图、表演容量和空间状态是否成立 | [导演规划审核](references/video.md)的“完整导演方案审核” |
| 案件、游戏、骗局的规则、时间线、理性反制与结论能否成立 | [承重机制](references/story-unit.md) |
| 复杂叙事因果、跨集知情与伏笔关系，或难以定位的戏剧问题 | [叙事诊断](references/narrative-diagnostics.md)的相关专项方法 |
| 空间轴线、动作衔接、人物身份、声源归属或音画同步等具体疑点 | [视听专项复核](references/video.md) |
| 组织或工单指定的歌词、音乐设计与实际音频专业审查 | [音乐审查](references/music.md) |

证据尺度、结论写法、只读边界与修订复核要求统一见[共同复核方法](references/reviewer.md)；审查记录按当前组织产物约定与工单保存。
