# 开源参考与改写说明

初始源码包按个人 Workbench 研发场景整理，声明员工身份、组织方法和技能文本为独立适配，参考以下公开项目的理念与工作流程。当前方法按目标工程的平台、技术栈和实际工具采用；以下来源说明不代表已核验第三方当前版本或运行效果。

1. **obra/superpowers** — https://github.com/obra/superpowers ：`test-driven-development`、`systematic-debugging`、`verification-before-completion`、`writing-plans`、`requesting-code-review`、`using-git-worktrees`、`finishing-a-development-branch`；用于测试、调试、计划、审查、Git 协作及验证规范。
2. **github/awesome-copilot** — https://github.com/github/awesome-copilot ：`skills/webapp-testing`、`skills/playwright-generate-test`、agent governance / skills discovery；用于真实 UI 测试与选择适合的能力。
3. **microsoft/playwright-mcp** — https://github.com/microsoft/playwright-mcp ：理解可用浏览器自动化工具，**未打包**该 MCP 的软件和服务。
4. **agentskills/agentskills** — https://github.com/agentskills/agentskills ：标准 `SKILL.md` 头部、按需引用 refs 的目录约定。
